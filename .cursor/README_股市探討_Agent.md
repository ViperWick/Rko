# 股市探討 AI Agent — 怎麼用

這是在 **Cursor** 裡的一組**對話規則**（不是另裝一支獨立程式）。用途：你想**專心聊大盤、產業、個股邏輯、風險與情境**時，讓 AI 用「研究員式討論」來回你，而不是閒聊或亂給買賣口令。

---

## 規則檔在哪

- **`.cursor/rules/stock-market-discussion-agent.mdc`**

內容重點：

- 角色：**探討與拆解**，非投顧、非保證報酬。
- 會要求釐清標的／週期／風險，並**正反觀點**並陳。
- 若你要連自己的倉位討論，可搭配讀 `etoro_trading/data/portfolio_summary.json`（有檔再讀）。

---

## 怎麼「開啟」這個 Agent

1. **在 Cursor 聊天時 @ 規則**  
   輸入 `@`，選 **Rules** → 勾選 **`stock-market-discussion-agent`**（或名稱含「股市探討」的那一條）。

2. **或用 Agent / 規則選擇器**  
   開新對話前，在規則列表裡啟用上述規則。

3. **直接開話題**  
   因本規則 `alwaysApply: false`，不一定每次都自動套上；**要穩定行為建議仍用 @ 規則**。

---

## 建議開場例句

- 「用股市探討 agent 的角度：半導體這一輪循環可能卡在哪個變數？」
- 「幫我用多／空兩邊各三個論點拆一下某某產業。」
- 「我持倉偏科技股，若利率高原型比預期久，可能踩到哪些風險？」（若要我讀倉，先執行過 `export-portfolio` 或跟我說一聲幫你跑。）

---

## 和 eToro 策略規則的關係

| 規則 | 用途 |
|------|------|
| `etoro-strategy-agent.mdc` | 你的 **eToro 組合、DCA、止盈止損、UI 摘要** 等執行面討論（常駐套用）。 |
| `stock-market-discussion-agent.mdc` | **市場與個股邏輯**的較廣泛探討（需要時 @ 啟用）。 |

兩者可並用：例如先用股市 agent 拆產業，再用 eToro 規則對照你實際持倉。
