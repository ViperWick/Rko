# 依據市場動作的策略

「依據市場動作」= 看**價格、成交量、波動**當下的表現來決定買賣或加減碼，而不是只看固定日期或固定比例。

---

## 你程式裡已經有的

| 策略 | 依據的「市場動作」 | 用途 |
|------|-------------------|------|
| **零售訊號（動量）** | 近 20 日漲跌幅 | 跌多→加碼、漲多→減量（逆向散戶） |
| **60 日均線** | 現價 vs MA60、偏離% | 價 > MA60 且偏離夠→加碼；價 ≤ MA60→跳過 |

在 UI 的「策略」頁可勾選「零售訊號優化」，一鍵執行時也會用到上述邏輯。**所有訊號與綜合評分皆改為使用 eToro API 取價。**

## 常見「依市場動作」的擴充方向

### 1. 動量（你已有）
- **看什麼**：過去 N 日報酬率。
- **動作**：跌多加碼 / 漲多減量，或順勢（漲多才加碼）。
- **你已有**：`retail_signals.py` 的 20 日動量 + buy_more / buy_less。

### 2. 趨勢過濾（你已有）
- **看什麼**：現價 vs 均線（如 MA20、MA60）。
- **動作**：價在均線上且偏離夠→買/加碼；價在均線下→不買或減倉。
- **你已有**：`ma_signals.py` 的 MA60 訊號。

### 3. 超買超賣（RSI）✅ 已實作
- **看什麼**：RSI（14 日）。
- **動作**：RSI &lt; 30 → 加碼 1.2x；RSI &gt; 70 → 減量 0.5x；其餘正常。
- **模組**：`rsi_signals.py`，在 UI 可選「RSI」訊號類型。

### 4. 突破（Breakout）✅ 已實作
- **看什麼**：收盤價 vs 過去 20 日最高/最低。
- **動作**：收盤 &gt; 20 日高 → 加碼 1.2x；收盤 &lt; 20 日低 → 減量 0.5x；其餘正常。
- **模組**：`breakout_signals.py`，在 UI 可選「突破」訊號類型。

### 5. 波動度 ✅ 已實作
- **看什麼**：近 20 日收盤報酬的標準差（%）。
- **動作**：波動高（≥3%）→ 減量 0.6x；波動低（&lt;1%）→ 略加碼 1.1x；其餘正常。
- **模組**：`volatility_signals.py`，在 UI 可選「波動度」訊號類型。

### 6. 成交量確認
- **看什麼**：今日量 vs 近期平均量（如 20 日均量）。
- **動作**：上漲 + 放量→趨勢較可信；上漲 + 縮量→減量或觀望。
- **擴充**：需有成交量資料（eToro / yfinance 有），可做「量價配合」過濾。

### 7. 均線多空排列
- **看什麼**：短均線 &gt; 長均線（如 MA5 &gt; MA20 &gt; MA60）。
- **動作**：多頭排列→順勢加碼；空頭排列→不買或減倉。
- **擴充**：在現有 MA60 上再加 MA20，做簡單多空排列判斷。
