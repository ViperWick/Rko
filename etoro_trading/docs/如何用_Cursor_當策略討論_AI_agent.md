# 如何用 Cursor 當「策略討論」AI Agent

你想用 AI agent 的方式跟「我」（Cursor 裡的 AI）討論你的 eToro 策略時，可以照下面做，我就會依你的**實際組合與當前訊號**來回覆。

---

## 模式 A：懶得翻檔——直接對話叫我查（推薦）

你的目標若是：**平常跟我聊天，由我幫你調用資料**，不必自己開一堆檔案：

1. **看帳戶、按鈕下單** → 仍用 **Streamlit UI**（`啟動檔/run_ui.bat`）。
2. **問數字、問持倉、問要怎麼調策略** → 在 **Cursor 這裡直接問**，例如：
   - 「幫我看目前持倉與現金比例」
   - 「依照 `portfolio_summary.json` 前五大標的是誰」
   - 「幫我跑 export-portfolio 再總結」
3. 專案已設規則（`.cursor/rules/etoro-strategy-agent.mdc`）：我會**優先用終端** `py -m etoro_trading portfolio` 或讀 `etoro_trading/data/` 裡的 JSON／`docs/` 報表來回答。

資料路徑速查：**`AI對話時資料從哪來.md`**（同資料夾）。

> 若未設定 `.env` 或 API 失敗，我會改讀你上次匯出的 JSON，或請你先開 UI／終端連線一次。

---

## 步驟一：產出「策略討論摘要」（讀取你的組合）

1. 開啟 eToro 交易程式的 **Streamlit UI**（例如從 `啟動檔/run_ui.bat` 或 `streamlit run etoro_trading/ui/app_ui.py`）。
2. 進入 **「策略」** 頁。
3. 在 **「🤖 與 AI 討論 — 根據我的組合與當前訊號」** 區塊，按 **「產生策略討論摘要（讀取我的組合）」**。
4. 畫面上會出現：
   - 你的組合概況（餘額、現金比例、未實現損益）
   - 各持倉與綜合評分（評分 1–10、建議加碼/正常/減量、DCA 倍數）
   - 系統摘要（一句話：當前形勢建議）
   - **一段可複製的完整文字**（討論用 prompt）。

---

## 步驟二：在 Cursor 裡開對話，貼上摘要與我討論

1. 在 Cursor 開一個 **新 Chat**（或在此專案裡跟我對話）。
2. **複製** UI 裡「複製以下內容到與 AI 的對話」底下的整段文字，**貼到對話框**。
3. 直接問你的問題，例如：
   - 「根據上面我的組合，你覺得這週適合執行一鍵執行嗎？」
   - 「我該用哪種訊號類型？綜合還是 RSI？」
   - 「現金比例偏低，你建議我先做止盈還是暫停 DCA？」
4. 我就會依你貼的**組合與評分數據**，以策略顧問身份回覆具體建議（例如：減量 DCA、用綜合訊號、先觀望某標的等）。

---

## 專案裡已幫你設好的「Agent 行為」

- 在此專案中已加入 **Cursor 規則**（`.cursor/rules/etoro-strategy-agent.mdc`）：  
  當你貼上策略討論摘要或問策略相關問題時，我會自動以**策略討論顧問**身份回應，並依據你提供的數據給建議。
- 不需要另外「做一個」AI agent 程式：**你 + Cursor 對話 + 這段摘要**，就是在這裡的 AI agent 討論方式。

---

## 可選：把摘要存成檔案，用 @ 提到

- 產出摘要後，按 **「儲存摘要到檔案（可在 Cursor 用 @ 提到此檔）」**，會把當次討論用文字存成 `etoro_trading/docs/策略討論_YYYY-MM-DD.md`。
- 在 Cursor 開新 Chat 時，用 **@ 檔案** 選該檔案（例如 `策略討論_2025-03-17.md`），再問「根據這份摘要跟我討論策略」，我就能直接讀取該檔當上下文。

---

## 小結

| 你要做的 | 說明 |
|----------|------|
| 在 eToro UI 按「產生策略討論摘要」 | 用你的 eToro 組合與 eToro 數據產出討論用文字 |
| 複製那段文字 → 貼到 Cursor 對話 | 提供給我「你的組合 + 當前訊號」的上下文 |
| 問「最近形勢適合什麼策略」等問題 | 我會依你貼的數據以策略顧問身份回覆 |

這樣就是在 **Cursor 這邊**用「我」當作你的策略討論 AI agent 的完整流程。
