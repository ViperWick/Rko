# 防務板塊策略應用說明

## 一、板塊邏輯：為何可視為防禦性配置

| 面向 | 說明 |
|------|------|
| **地緣政治** | 區域緊張時，各國國防預算與採購增加，有利防務股 |
| **政府訂單** | 合約長、能見度高，營收較不受景氣波動影響 |
| **產業特性** | 進入門檻高，寡占市場，定價能力較強 |
| **分散效果** | 與科技、消費股相關性較低，可降低組合波動 |

⚠️ 仍屬景氣循環股，且易受政策與地緣事件影響，宜控制部位與再平衡。

## 三、與你現有策略的銜接

### 策略原則回顧

- **股票：只減不加**（不新開倉，止盈時減倉）
- **ETF：順勢加倉**（價 > MA60 且偏離 ≥ 2%）
- **現金不足**（< 15%）時，才考慮止盈、保留 1/3

### 應用方式

| 情境 | 建議 | 說明 |
|------|------|------|
| **未持有防務股** | 列入觀察名單 | 不主動買，若有 DCA 或策略放寬再考慮 |
| **已持有 LMT、RTX 等** | 沿用既有股票規則 | 止盈 ≥ 20% 時減倉，保留 1/3 |
| **想增加防禦配置** | 優先用 ETF | 如 ITA、XAR 等國防 ETF（若 eToro 有） |
| **策略放寬可買股票** | 可納入防務板塊 | 小額、分批，佔組合比例 < 10% |

### 推薦納入 `strategy_config.json`

在 `etf_buy_list` 旁，可新增 `defense_watchlist` 區塊，供 UI 或腳本讀取：

```json
"defense_watchlist": {
  "role": "觀察/擇機",
  "symbols": ["LMT", "RTX", "NOC", "GD", "LHX", "RHM.DE", "LDO.MI"],
  "amount": "$200-300",
  "note": "依股票規則：只減不加，或策略放寬時小額配置"
}
```
