# 量子產業 — 各國監管與認證／法規概覽（研究用）

> **極重要**  
> - 本檔為**一般性整理**，**不是**法律、稅務、出口合規或投資建議。  
> - 法規**變動快**（尤其**出口管制、投資審查、AI／量子條款**）；實務請諮詢**持牌律師／合規顧問**並查**官方原文**。  
> - **各公司「必須」通過哪張證**取決於：**賣給誰**（國防／金融／醫療）、**在哪上市**、**產品形態**（硬體／軟體／雲）、**資料是否跨境**——無法用一句話套全部。

**整理時點**：2026-03-21

## 一、先分三種「監管壓力來源」

| 類型 | 典型法規／工具 | 誰最敏感 |
|------|----------------|----------|
| **出口與軍民兩用** | 美國 **EAR**、**ITAR**（若涉國防品）、歐盟 **Dual-Use**、英國、日本等清單 | 量子**硬體**、**低溫控制**、**特定軟體／技術**、對**中國等**目的地 |
| **投資與供應鏈安全** | 美 **CFIUS**、歐 **FDI screening**、各國「關鍵技術」外資審查 | **併購**、**外國股東**、**政府補助案** |
| **資安與密碼產品** | **NIST PQC** 標準、**FIPS 140-3**、**Common Criteria**、產業標準（PCI、醫療 FDA／MDR 等） | **後量子加密**、**晶片安全元件**、進**政府／金融**供應鏈 |

## 二、主要經濟體 — 高度精簡（請當「地圖」用）

### 美國

- **出口**：商務部 **BIS**（**EAR**）、國防相關則 **State/ITAR** 體系；量子相關**軟硬體與技術**可能落在**軍民兩用**或特定 **ECCN**；**中國等**目的地常額外嚴格。  
- **投資**：**CFIUS** 審敏感行業投資與併購。  
- **政府採購／國防**：**FedRAMP**（雲服務）、**FIPS 140**（密碼模組）、**CMMC**（國防供應鏈網安成熟度）、**Trusted Foundry／供應商資格**（晶圓代工常見）。  
- **證券**：**SEC** 披露；量子敘事屬**高風險揭露**（MD&A、Risk Factors）。

### 歐盟／英國

- **出口**：歐盟 **Dual-Use Regulation**；英國獨立清單（脫歐後）。  
- **資料與產品**：**GDPR**、**NIS2**（關鍵基礎設施網安）、**CRA**（產品網安條款逐步生效中）。  
- **密碼**：成員國對密碼產品**進口／使用**曾有不同申報傳統；**企業合規**常對齊 **Common Criteria**、客戶要求的 **eIDAS** 相關場景（視產品）。  
- **英國**：**NCSC** 指引、政府合約常要求與 **Cyber Essentials** 等（視標案）。

### 加拿大

- **出口**：**Global Affairs** 軍民兩用清單；對美供應鏈需兼顧美國規則。  
- **上市**：**TSX/TSXV** 披露；小盤量子股常見**募資與權證**揭露。  
- **隱私**：**PIPEDA** 等（量子安全通訊產品若處理個資仍適用）。

### 中國

- **出口與技術**：**商務部／海關**管制清單、**密碼法**、**網安法／數安／個資**體系；量子相關技術屬**高度敏感**領域之一。  
- **對外上市／融資**：跨境合規與審計披露要求需**本地顧問**。

### 日本、韓國、澳洲等

- 多有**軍民兩用出口**清單與**外資投資審查**；韓國與量子國家計畫結合時常有**政府專案合規**。  
- **細節請查各國貿易主管機關英文／本地官網**。

## 三、常見「認證／標準」— 與量子板塊的關係

| 名稱 | 約略是什麼 | 誰常需要 |
|------|------------|----------|
| **NIST PQC（FIPS 203/204/205 等）** | **後量子密碼演算法標準** | **Arqit、01、BTQ、QeM、SEALSQ** 等密碼／晶片敘事；進美國聯邦客戶常要「對齊 NIST」 |
| **FIPS 140-3** | 密碼**模組**安全驗證（美） | **HSM、安全晶片、SEALSQ** 路線產品進政府／金融 |
| **Common Criteria (CC)** | 國際資安產品評估（**EAL** 等級） | 歐洲政府、電信、大企業採購資安設備 |
| **FedRAMP** | 美國聯邦雲服務授權 | **IonQ/Rigetti/D-Wave** 等若賣 **Fed** 雲用量子即服務需長期布局（多為間接透過 **AWS Braket** 等） |
| **CMMC / DFARS** | 美國國防供應鏈網安 | **SkyWater** 等 **Trusted** 代工、國防次系統 |
| **ITAR / EAR compliance** | 國防出口 vs 兩用出口合規計畫 | 有**國防合約**或**受控技術**的公司內部必備流程（未必是「一張證」） |
| **FDA / MDR / ISO 13485** | 醫材／品質系統 | 量子用於**醫藥研發**不必然等於醫材；若產品本身是醫材才適用 |
| **上市交易所規則** | 披露、內控 | **所有上市公司** |

## 四、對照你「觀察清單」— 哪類公司通常要盯什麼（非逐家法律結論）

以下為**商業模式對照**，**不是**「該公司已通過某某證」的陳述；實際以**合約與年報**為準。

### A 純量子（硬體／雲）

| 代表 | 監管／合規焦點 |
|------|----------------|
| **IonQ、Rigetti、D-Wave、Infleqtion、Xanadu、IQM、Pasqal、Quantinuum** | **出口與技術轉讓**（目的地、合作國）、**政府專案**的資安條款、對**聯邦／軍方**銷售時的**供應鏈與資安**；雲端交付牽涉**客戶所在地資料法**。 |
| **QCI（QUBT）** | 若主軸為**量子通訊／加密**，則另加**密碼產品**與**電信設備**進口國規則。 |

### B 量子安全（軟體／晶片）

| 代表 | 監管／合規焦點 |
|------|----------------|
| **Arqit、01、BTQ、QeM** | **NIST PQC** 對齊、**FIPS**／**CC**（視客戶）、電信**設備認證**（國別差異大）。 |
| **SEALSQ** | **PQC 晶片**、**FIPS 140-3**、**國防供應商**資格（如與 **TSS** 類合作敘事）、**出口分類**。 |

### C 供應鏈

| 代表 | 監管／合規焦點 |
|------|----------------|
| **SkyWater** | **DMEA Trusted Foundry**、**ITAR/EAR** 內部合規、國防長約；**併購**時 **CFIUS** 等。 |
| **AmpliTech** | 國防／航太客戶則 **EAR/ITAR** 與品質系統（**AS9100** 等，視客戶要求）。 |
| **ASP Isotopes** | **核材料／濃縮**專屬監管（**NRC**、國際原子能規範、出口許可）；與「量子敘事」不同軸。 |

### D 大廠

| 代表 | 監管／合規焦點 |
|------|----------------|
| **IBM、MSFT、GOOGL、AMZN、INTC、HON** | 全集團**出口合規**、**隱私**、**政府雲資格**；量子多為**研發與子產品線**，合規由集團架構吸收。 |

## 五、你實務上可以怎麼查「這家公司要不要某張證」

1. 讀 **10-K / 20-F** 的 **Risk Factors**、**Government regulation**、**Export controls**。  
2. 搜公司名 + **`export control`**、**`FIPS`**、**`Common Criteria`**、**`ITAR`**。  
3. 政府合約：搜 **SEC** **`awarded`**、**`prime contract`**、**`DoD`**。  
4. 歐洲客戶：年報是否提 **dual-use**、**GDPR**、**CRA**。
