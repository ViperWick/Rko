## 二之一、純量子 — 逐檔研究筆記（依第七節五點檢查）

> 下列為**架構化筆記欄位**：數字、百分比、合約占比等**請你自行對照最新季報／年報／IR 簡報核實**，並在欄位旁打勾或註日期。  
> 符號說明：**〔待核〕**＝你尚未查證；**〔已核 YYYY-MM-DD〕**＝你已對照過文件。

### IonQ（IONQ）

1. **技術路線**：離子阱；強項常見描述為閘極保真度、與雲端／企業合作敘事。**〔待核〕** 最新一代系統與路線圖。  
2. **營收結構**：**〔待核〕** 政府／研究 vs 商業客戶占比；是否以「量子即服務」或一次性專案為主；經常性收入（若有揭露）。  
3. **現金與稀釋**：**〔待核〕** 現金跑道、庫藏股／增資／可轉債、股權激勵費用對每股盈虧的影響。  
4. **競品對照**：同路線 **Quantinuum（未上市）**；可橫向對照 **超導（RGTI）／中性原子（INFQ、Pasqal）／退火（QBTS）** 的商業進展節奏。  
5. **催化劑日曆**：**〔待核〕** 下次財報日、技術發表、大型合作公告、法說會重點指引。

### Rigetti Computing（RGTI）

1. **技術路線**：超導量子位元；自有晶圓／製造鏈為常見討論點。**〔待核〕** 最新位元數、錯誤率、雲端可用區域。  
2. **營收結構**：**〔待核〕** 合約型收入 vs 產品化；客戶集中度；是否仍高度依賴研發期收入。  
3. **現金與稀釋**：**〔待核〕** 融資歷史與股本變化；現金跑道。  
4. **競品對照**：**IQM（將上市）**、**IBM 超導雲**（非純量子股）—比「技術里程碑」與「商業訂單可見度」。  
5. **催化劑日曆**：**〔待核〕** 財報、新處理器發表、與雲端或國家實驗室合作。

### D-Wave Quantum（QBTS）

1. **技術路線**：量子退火為核心；亦常見「閘控／混合運算」延伸敘事。**〔待核〕** 與你投資假設是否一致。  
2. **營收結構**：**〔待核〕** 企業優化／物流等應用案例是否轉成可重複收入；政府標案占比。  
3. **現金與稀釋**：**〔待核〕** 小型股波動與融資循環。  
4. **競品對照**：退火路線競品相對少，可比較對象常變成「**通用量子雲整體滲透率**」與客戶預算。  
5. **催化劑日曆**：**〔待核〕** 財報、新客戶案例、退火硬體更新。

### Quantum Computing Inc.（QUBT）

1. **技術路線**：公司以光子／量子軟體平台等為官網敘事，**細節以 IR 為準**。**〔待核〕** 實際產品線與專利布局。  
2. **營收結構**：**〔待核〕** 是否仍偏早期／一次性專案；有無明確標竿客戶與合約長度。  
3. **現金與稀釋**：**〔待核〕** 小型股常見增資；對你持有成本的影響。  
4. **競品對照**：與 **IONQ／RGTI／QBTS** 路線不同，比較時應分開「硬體量子位元」與「軟體／光子硬體」故事。  
5. **催化劑日曆**：**〔待核〕** 財報、產品發表、合作案。

### Infleqtion（INFQ）

1. **技術路線**：中性原子；可對照 **Pasqal** 同路線差異（規模化、保真度、應用場景）。**〔待核〕** 最新技術里程碑。  
2. **營收結構**：**〔待核〕** 上市後首份年報／季報之收入組成與指引。  
3. **現金與稀釋**：**〔待核〕** IPO／SPAC 後股本與費用率。  
4. **競品對照**：**Pasqal**、其他中性原子新創（多未上市）。  
5. **催化劑日曆**：**〔待核〕** 財報、政府／實驗室合作、與 AI／HPC 生態結合消息。  
6. **eToro**：**〔待核〕** 見 `量子計算板塊_eToro可交易清單.md` — 目前 API 搜尋 `INFQ` 未命中，請以 App 實測為準。

### Xanadu Quantum（XNDU）

1. **技術路線**：光子（光量子）；與多數「固態」路線不同，製造與擴展邏輯也不同。**〔待核〕** 良率、規模化路徑。  
2. **營收結構**：**〔待核〕** 上市初期揭露。  
3. **現金與稀釋**：**〔待核〕** SPAC 合併條款、PIPE、攤薄。  
4. **競品對照**：**QUBT（光子敘事若有重疊）**、離子阱／超導大廠—比「雲端可用性」與「實際工作負載案例」。  
5. **催化劑日曆**：**〔待核〕** 掛牌後首份財報、技術 demo、合作案。  
6. **eToro**：**〔待核〕** 目前 API 搜尋 `XNDU` 未命中。

### IQM Quantum Computers（上市進行中，代碼待定）

1. **技術路線**：超導；歐洲量子生態代表之一。**〔待核〕** SPAC 合併後正式代碼與交割日。  
2. **營收結構**：**〔待核〕** 歐洲政府與研究單位占比預期。  
3. **現金與稀釋**：**〔待核〕** 合併估值、攤薄、現金進帳。  
4. **競品對照**：**RGTI**、**IBM**。  
5. **催化劑日曆**：**〔待核〕** SEC／投資人簡報更新、合併完成日、首份公開財報。

### Pasqal（上市規劃中，代碼待定）

1. **技術路線**：中性原子。**〔待核〕** 與 **INFQ** 的差異化（軟體、硬體、地理與客戶）。  
2. **營收結構**：**〔待核〕** 商業化階段與訂單能見度。  
3. **現金與稀釋**：**〔待核〕** SPAC 或雙掛牌條款。  
4. **競品對照**：**INFQ**。  
5. **催化劑日曆**：**〔待核〕** 掛牌時程、歐洲／美國監管文件。

### Quantinuum（IPO 準備中，代碼待定）

1. **技術路線**：離子阱＋軟體生態（如 TKET 等）。**〔待核〕** 與 **IONQ** 同路線競爭格局。  
2. **營收結構**：**〔待核〕** Honeywell 歷史關聯與分拆後報表。  
3. **現金與稀釋**：**〔待核〕** IPO 招股書（出現後）—股本、大股東售股比例。  
4. **競品對照**：**IONQ**。  
5. **催化劑日曆**：**〔待核〕** S-1／招股書公開、路演、掛牌日。  
6. **間接曝險**：上市前若研究「供應鏈／大股東」，可同步看 **HON**（**股價驅動通常非量子**，見第五節免責）。

## 七、研究檢查清單（每檔標的至少看這 5 點）

1. **技術路線**：離子阱／超導／中性原子／光子／退火——路線不同，風險與時間軸不同。  
2. **營收結構**：有多少是政府／研究合約？多少是商業客戶？是否經常性收入？  
3. **現金與稀釋**：上市後庫藏股、增資、可轉債對小股東的影響。  
4. **競品對照**：同一路線至少有 1～2 家可直接比較（例如中性原子：Infleqtion vs Pasqal）。  
5. **催化劑日曆**：財報日、技術發表（論文／大會）、政府標案、大型雲端合作公告。
