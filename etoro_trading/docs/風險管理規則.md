# 風險管理規則

> 本文集中說明「風險管理」的規則與門檻，與程式中的止盈止損、現金比例、監控邏輯對應。策略與參數細節見 [交易規則與參數](./交易規則與參數.md)。

---

## 一、總則

| 原則 | 說明 |
|------|------|
| **現金為王** | 先看現金比例，再決定能否加倉、是否必須止盈補現金 |
| **止損可關、止盈建議開** | 波動大時可關止損避免被洗出；止盈建議保留，鎖利並釋放現金 |
| **依資產區塊分開規則** | 股票 / ETF / 槓桿 ETF / 加密貨幣，加減倉規則不同 |
| **集中度與虧損曝險** | 單一標的或虧損部位過大時，優先減壓 |

---

## 二、現金比例規則（現金本位）

程式與腳本中的門檻與你既有邏輯一致，可直接當成「第一道風控」。

### 2.1 門檻定義

| 現金比例 | 等級 | 動作原則 |
|----------|------|----------|
| **≥ 25%** | 充足 | 可執行 ETF / 槓桿 ETF 加倉；不止盈也沒關係，保留倉位讓長期翻倍 |
| **15%～25%** | 尚可 | 觀察中；現金不足時再執行止盈 |
| **5%～15%** | 偏低 | **需止盈補充現金**：優先賣出獲利 ≥ 20% 的持倉，每標的至少保留 1/3 倉位 |
| **< 5%** | 極低 | **必須止盈**；暫停所有加倉（DCA、槓桿 ETF 抄底等），先恢復現金 |

### 2.2 對應程式與數據

- **風險評分**：`risk_score.py` 中「現金緩衝」維度會依現金比例給 10（充足）～90（極低）分。
- **策略建議**：`check_yesterday_changes.py` 的「現金本位」區塊依上述門檻給建議。
- **計算方式**：現金比例 = `可用餘額(credit) / 總資產(credit + 持倉市值)`。

### 2.3 實務口訣

```
現金 ≥ 25% → 可加倉、不止盈
現金 15～25% → 觀察，不夠再止盈
現金 < 15% → 止盈補現金，保留 1/3 倉位
現金 < 5%  → 只做止盈與減倉，不加倉
```

## 三、止損規則

### 3.1 門檻與觸發

| 項目 | 說明 |
|------|------|
| **觸發條件** | 單筆持倉的「虧損%」≤ 設定的止損門檻（例如 -10%） |
| **動作** | 該筆持倉**整筆平倉**（程式為市價平倉，不保留部分） |
| **預設參數** | 例如 `-10` 表示虧 10% 就止損；可依標的波動性自行調高/調低 |

### 3.2 何時「關閉」止損

| 情境 | 建議 |
|------|------|
| 波動極大的標的（如槓桿 ETF、加密、小盤股） | 可**關閉自動止損**（`monitor --no-stop-loss`），避免被洗出；改用手動或較寬門檻 |
| 波動較小的標的（如大型股、部分 ETF） | 建議保留止損，例如 -10%～-15% |

### 3.3 程式用法

- **監控迴圈**：`python -m etoro_trading monitor --stop-loss -10` 會每輪檢查並對觸及 -10% 的持倉平倉。
- **關閉止損**：`python -m etoro_trading monitor --no-stop-loss`，只做止盈、不做止損。
- **單次檢查**：`strategy.check_stop_loss(loss_threshold_pct=-10, client)`。

### 3.4 注意

- 止損看的是**單筆**持倉的損益%，不是該標的總倉位。
- 同一標的多筆倉位會分別檢查，可能只平掉其中幾筆。

## 四、止盈規則

### 4.1 門檻與觸發

| 項目 | 說明 |
|------|------|
| **觸發條件** | 單筆持倉的「獲利%」≥ 設定的止盈門檻（例如 20%） |
| **動作** | 按**標的**分組，每標的至少保留 `keep_ratio`（預設 1/3）倉位，其餘可止盈的倉位中，優先平掉「獲利%最高」的單筆（或部分單位） |
| **預設參數** | 止盈 20%、保留 1/3：`--take-profit 20 --keep-ratio 0.333` |

### 4.2 保留比例（keep_ratio）

| keep_ratio | 意義 |
|------------|------|
| **1/3（0.333）** | 每標的至少保留 1/3 倉位，讓剩餘部位有機會長期翻倍；其餘達標的獲利可先鎖定 |
| **0** | 達標就全部止盈，不保留（較積極鎖利，較不利長期複利） |

### 4.3 程式用法

- **監控迴圈**：`python -m etoro_trading monitor --take-profit 20 --keep-ratio 0.333`。
- **單次檢查**：`strategy.check_take_profit(profit_threshold_pct=20, keep_ratio=1/3, client)`。

### 4.4 與現金規則的配合

- 當**現金 < 15%** 時：應積極執行止盈（獲利 ≥ 20% 的持倉），用鎖利來補充現金。
- 當**現金 ≥ 25%** 時：可選擇不止盈，讓倉位繼續跑；若仍想鎖利，可維持 20% 止盈 + 保留 1/3。

## 五、資產區塊規則（加減倉方向）

不同資產類型採用不同風控與加減倉邏輯，與你既有策略一致。

### 5.1 總表

| 資產區塊 | 加倉 | 減倉 | 備註 |
|----------|------|------|------|
| **股票** | 只減不加 | 止盈時減倉；現金不足時優先止盈獲利 ≥ 20% 者 | 不新開倉，以減倉與鎖利為主 |
| **ETF** | 可加倉 | 止盈時減倉 | 價 > MA60 且偏離 ≥ 2% 時順勢加碼（DCA+MA60） |
| **槓桿 ETF（TQQQ、SOXL 等）** | 可加倉 | 止盈時減倉 | 回撤 25% / 35% / 45% 分批買跌；波動大可關止損 |
| **加密貨幣** | 暫不加倉 | 止盈時可減倉 | 質押利息為主，不加倉 |

### 5.2 股票

- **不加新倉**：不新開股票倉位。
- **減倉時機**：觸及止盈（如 20%）時減倉，或現金 < 15% 時優先賣出「獲利 ≥ 20%」的持倉，每標的保留 1/3。

### 5.3 ETF

- **加倉條件**：價 > MA60 且偏離 ≥ 2% 時，可執行 DCA（如 `dca-ma60`）。
- **減倉**：同一般止盈規則。

### 5.4 槓桿 ETF

- **加倉**：回撤 25% / 35% / 45% 分批買跌；需在現金充足（≥ 25%）時執行。
- **止損**：可關閉自動止損（`--no-stop-loss`），避免劇烈波動被洗出。

### 5.5 加密貨幣

- **不加倉**：目前策略為只持有、吃質押利息，不加新倉。
- **減倉**：若觸及止盈可減倉，或依個人需要手動調整。

## 六、集中度與虧損曝險

風險評分（`risk_score.py`）會算集中度、虧損佔比、高風險資產佔比，可當成「何時要主動減壓」的參考。

### 6.1 集中度風險（HHI）

| 概念 | 說明 |
|------|------|
| **指標** | 持倉權重平方和（HHI），愈高表示愈集中在少數標的 |
| **高集中** | 前幾檔佔比過高時，單一標的大跌會明顯拖累組合 |
| **建議** | 單一標的或單一產業不建議超過總倉位過高比例（例如單一標的 < 15～20%） |

### 6.2 虧損曝險

| 概念 | 說明 |
|------|------|
| **虧損 > 30%** | 程式會算「虧損超過 30% 的持倉市值」佔組合比例；佔比過高會拉高風險分數 |
| **虧損 10%～30%** | 中度虧損區，同樣計入「虧損曝險」維度 |
| **建議** | 若虧損部位佔組合過大，優先考慮：止損或減倉最差的幾筆、或不再加碼該標的 |

### 6.3 虧損集中度（虧損 > 20%）

| 概念 | 說明 |
|------|------|
| **指標** | 虧損超過 20% 的持倉，其市值加總佔組合比例 |
| **建議** | 該比例過高時，應優先減倉或止損，降低「虧損集中度」 |

### 6.4 高風險資產曝險

| 概念 | 說明 |
|------|------|
| **高風險資產** | 加密貨幣 + 槓桿/反向 ETF（見 `risk_score.py` 的 `CRYPTO_SYMBOLS`、`LEVERAGED_ETF`） |
| **指標** | 這類資產市值佔組合比例 |
| **建議** | 佔比過高時，整體波動與爆倉風險較大；可依風險承受度降低比例或減少加倉 |

## 七、監控頻率與執行順序

### 7.1 建議頻率

| 頻率 | 動作 |
|------|------|
| **每週 1 次** | 查持倉、看現金比例、檢查是否觸及止盈/止損；必要時執行平倉或匯出報表 |
| **每月 1 次** | 檢視風險評分、集中度與虧損曝險；決定本月是否執行 DCA、是否先止盈補現金 |

### 7.2 每次檢查的順序（建議）

1. **看現金比例**  
   - ≥ 25%：可加倉、可選擇不止盈。  
   - < 15%：必須靠止盈補現金，優先處理獲利 ≥ 20% 的持倉。

2. **看止盈**  
   - 若開啟監控止盈：跑 `monitor` 或單次 `check_take_profit`，依「保留 1/3」規則執行。

3. **看止損**  
   - 若未關閉止損：跑 `check_stop_loss` 或 `monitor --stop-loss -10`。  
   - 若為高波動標的且已關止損：改用手動或較寬門檻。

4. **看集中度與虧損**  
   - 跑風險評分或匯出持倉彙總，看「虧損 > 20%／30% 佔比」「高風險資產佔比」；過高則規劃減倉或止損。

5. **加倉（僅在現金充足時）**  
   - ETF：檢查 MA60 與偏離，符合再 DCA。  
   - 槓桿 ETF：依回撤門檻分批買跌。

## 八、快速對照表

| 你想… | 對應規則 / 動作 |
|-------|------------------|
| 知道能不能加倉 | 看現金比例：≥ 25% 可加；< 5% 不加 |
| 知道要不要止盈 | 現金 < 15% → 要止盈補現金；獲利 ≥ 20% 的持倉可止盈，保留 1/3 |
| 設定止損 | `monitor --stop-loss -10`；高波動可 `--no-stop-loss` |
| 設定止盈 | `monitor --take-profit 20 --keep-ratio 0.333` |
| 股票要不要減倉 | 股票只減不加；現金不足時優先止盈獲利 ≥ 20% 的股票 |
| ETF 能不能買 | 價 > MA60 且偏離 ≥ 2%，且現金 ≥ 25% 時可 DCA |
| 槓桿 ETF 能不能買 | 回撤 25/35/45% 分批買；現金充足時；可關止損 |
| 加密要不要動 | 暫不加倉；可止盈減倉 |
| 看整體風險 | 跑風險評分腳本、看集中度與虧損曝險、現金緩衝 |
