>
> **目前配置**：股票只減不加、ETF 順勢加倉、加密貨幣暫不動（質押利息）、槓桿 ETF 保守買跌

## 二、資產配置架構（目前配置）

### 2.1 總體區塊

```
總資產 = 現金 + ETF + 槓桿 ETF + 加密貨幣（質押） + 股票（只減不加）
```

| 區塊 | 目前動作 | 說明 |
|------|----------|------|
| **現金** | 20–30% | 大跌加碼、生活備用 |
| **ETF** | **加倉** | 順勢（價 > MA60 且偏離 ≥ 2%） |
| **槓桿 ETF** | **加倉** | 保守買跌（回撤 25% / 35% / 45% 分批） |
| **加密貨幣** | **暫不動** | 目的為質押利息，不加倉 |
| **股票** | **只減不加** | 止盈時減倉，不新開倉 |

### 2.2 現金本位規則

| 規則 | 動作 |
|------|------|
| 現金 > 30% | 執行 ETF / 槓桿 ETF 買入 |
| 現金 < 20% | 當月暫停加倉 |
| 每月檢視 | 一次 |

## 三、買入策略（目前配置）

### 3.1 普通 ETF（GLD、ARKK、PAVE、QYLD 等）— 加倉

| 項目 | 規則 |
|------|------|
| **動作** | **加倉** |
| **策略** | 順勢投資 |
| **買入條件** | 價 > MA60 且偏離 ≥ 2% |
| **程式** | `dca-ma60` |
| **單筆** | $300–500 |
| **大跌時** | **不賣**，持有；接近底部有訊號時分批加碼 |

### 3.2 槓桿 ETF（TQQQ、SOXL、QLD、SSO）— 加倉（保守買跌）

| 項目 | 規則 |
|------|------|
| **動作** | **加倉** |
| **策略** | **保守買跌**（2x、3x 皆用買跌） |
| **買入時機** | 從 52 週高點回撤達門檻時分批 |
| **分批門檻** | 2x：回撤 25% / 30% / 35%；3x：回撤 25% / 35% / 45% |
| **單筆** | $100 |
| **現金保留** | 30–40%，留子彈等大跌 |

### 3.3 加密貨幣 — 暫不動

| 項目 | 規則 |
|------|------|
| **動作** | **不加倉** |
| **目的** | 質押利息 |
| **備註** | 持有部位不變，不新開倉 |

### 3.4 股票 — 只減不加

| 項目 | 規則 |
|------|------|
| **動作** | **只減倉** |
| **策略** | 不新開倉、不加碼 |
| **賣出** | 依止盈規則（現金不足時）減倉 |
| **方向** | 減倉後資金轉 ETF / 槓桿 ETF |

### 3.5 單筆金額參考

| 標的類型 | 單筆 | 說明 |
|----------|------|------|
| 普通 ETF | $300–500 | 順勢加倉 |
| 槓桿 ETF | $100 | 買跌分批 |
| 加密貨幣 | — | 暫不動 |
| 股票 | — | 不加倉 |

## 四、賣出策略

### 4.1 現金本位止盈（優先檢查）

| 現金倉位 | 動作 |
|----------|------|
| **現金 ≥ 25%** | **不止盈**，繼續持有 |
| **現金 < 15%** | **開始止盈**，賣出部分持倉換現金 |

**邏輯**：現金夠就不賣，讓部位繼續跑；現金不夠才止盈補充。

### 4.2 止盈規則（現金不足時執行）

| 項目 | 規則 |
|------|------|
| **觸發條件** | 現金 < 15% **且** 持倉獲利 ≥ 20% |
| **看單筆** | 每筆持倉獨立計算損益，非總倉位 |
| **選擇** | 優先止盈獲利%最高的那幾筆（eToro 可選單筆平倉） |
| **保留** | 每標的至少保留 **1/3** 倉位 |
| **備註** | 只賣有獲利的部位，不賣虧損部位換現金 |

### 4.3 大跌不賣

| 項目 | 規則 |
|------|------|
| **普通 ETF 大跌** | **不賣**，持有 |
| **動作** | 接近底部有止跌/反彈訊號時，分批加碼 |

### 4.4 止損

| 項目 | 規則 |
|------|------|
| **目前** | 暫停（波動大時不設） |
| **備註** | 市況穩定後再考慮 |

## 六、策略流程圖

### 6.1 普通 ETF 流程

```
價 > MA60 且偏離 ≥ 2%？
├── 是 → 買入（順勢）
└── 否 → 跳過

大跌中？
├── 是 → 不賣，持有
└── 否 → 依止盈規則

接近底部有止跌/反彈訊號？
└── 是 → 分批加碼
```

### 6.2 槓桿 ETF 流程（目前：全部買跌）

**2x、3x 皆用保守買跌：**
```
從 52 週高點回撤達門檻？
├── 2x：25% / 30% / 35% 分批
├── 3x：25% / 35% / 45% 分批
└── 有止跌/反彈訊號？
         ├── 是 → 分批買入（每筆 $100）
         └── 否 → 等待
```

### 6.3 賣出流程

```
現金比例？
├── 現金 ≥ 25% → 不止盈，繼續持有
└── 現金 < 15% → 檢查是否有獲利 ≥ 20% 的持倉
                  ├── 有 → 優先賣獲利%最高的那幾筆，保留 1/3
                  └── 無 → 不賣虧損部位，另尋現金來源

大跌？
└── 不賣（普通 ETF）
```
