# 日常自動化：不用每天手動跑腳本

目標：**每天固定時間**自動執行一連串指令（匯出持倉、今日總結、昨日漲跌檢查等），結果寫進 **`etoro_trading/data/automation_logs/`**，你只要偶爾看 log 或 JSON／md 即可。

---

## 一、先本機試跑

1. 確認 **`etoro_trading/.env`** 已設定 API 金鑰（要連 eToro 的步驟才會成功）。
2. 雙擊 **`啟動檔/run_daily_automation.bat`**  
   或直接執行腳本（路徑僅英文，避免編碼問題）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\User\.cursor-tutor\etoro_trading\scripts\run_daily_automation.ps1"
```

3. 只看會跑哪些、不真的執行：

```powershell
Set-Location C:\Users\User\.cursor-tutor\etoro_trading\scripts
.\run_daily_automation.ps1 -DryRun
```

4. 任一步失敗就**不要跑後面**：

```powershell
Set-Location C:\Users\User\.cursor-tutor\etoro_trading\scripts
.\run_daily_automation.ps1 -StopOnError
```

---

## 二、自訂每天要跑什麼

編輯 **`etoro_trading/scripts/run_daily_automation.ps1`** 里的 **`$Steps`** 陣列：

- 不需要的步驟整行註解掉或刪除。
- 可改成只跑例如：`export-portfolio`、`daily-performance`。
- 其他子命令與 **`py -m etoro_trading.scripts --help`** 一致。

---

## 三、Windows 工作排程器（每天自動）

1. 開啟 **工作排程器** → **建立工作**（建議不要用「簡易工作」）。
2. **一般**：名稱例如 `eToro 日常自動化`；可勾 **以最高權限執行**（若遇權限問題再試）。
3. **觸發程序**：**每天**，選你想要的時間（例如每天 07:00）。
4. **動作** → **啟動程式**：
   - **程式**：`powershell.exe`
   - **新增引數**（請改成你的實際路徑）：

```text
-NoProfile -ExecutionPolicy Bypass -File "C:\Users\User\.cursor-tutor\etoro_trading\scripts\run_daily_automation.ps1"
```

5. **設定**：可勾 **若工作失敗，依下列方式重新啟動**（選用）。
6. **條件／電源**：筆電注意「只有在使用交流電源時才啟動」是否會擋住。

電腦需在排程時間**開機且可連網**；若睡眠可能不會跑，請依需求調整電源設定。

---

## 四、結果在哪裡看

| 類型 | 位置 |
|------|------|
| 每次排程的完整輸出 | `etoro_trading/data/automation_logs/daily_*.log` |
| 持倉快取 | `etoro_trading/data/portfolio_summary.json` |
| 今日績效 JSON | `etoro_trading/data/daily_performance_report.json` |
| 今日總結 md | `etoro_trading/docs/今日總結_YYYY-MM-DD.md` |

---

## 五、安全提醒

- `.env` 金鑰僅存在本機，**不要**把 log 整包上傳到公開地方（log 可能含錯誤訊息與路徑）。
- 自動化會**呼叫 eToro API**；請遵守 eToro 使用條款與頻率，避免過度密集排程。

---

## 六、和 Cursor AI 的搭配

排程負責「每天固定產檔」；你在 Cursor 對話里可說：「幫我讀昨天自動化 log」或「根據 `portfolio_summary.json` 摘要」，減少自己開檔找資料的時間。

---

## 七、本機 Ollama 自動摘要 log（可選）

若已安裝 **Ollama**，可在排程跑完後用本機模型產生一段中文摘要，見：**[`Ollama_本機摘要設定.md`](Ollama_本機摘要設定.md)**。  
指令：`py -m etoro_trading.scripts ollama-summarize`
