### 1.2 各策略詳述

#### 策略 1：20 週均線 + 偏離過濾（原規劃）

| 項目 | 說明 |
|------|------|
| **類型** | 趨勢跟隨 |
| **買入** | 收盤價 > 20 週均線，且偏離均線 2–3% 以上時加碼 |
| **賣出** | 搭配止盈止損，或價跌破均線 |
| **參數** | MA 週期 20、偏離門檻 2–3% |
| **優點** | 順勢、減少假訊號 |
| **缺點** | 需 K 線資料、延遲較大 |
| **適用** | 中長期趨勢明顯的標的（如 GLD、大型股） |

#### 策略 2：DCA 定額定投

| 項目 | 說明 |
|------|------|
| **類型** | 被動累積 |
| **買入** | 每週／每月固定金額買入，不論漲跌 |
| **賣出** | 通常不賣，或搭配止盈止損 |
| **參數** | 週期（週/月）、單筆金額 |
| **優點** | 簡單、紀律、分散買入時點 |
| **缺點** | 下跌時持續買入可能心理壓力大 |
| **適用** | 長期看好、波動可接受的標的 |
| **程式** | `strategy.dca_buy()` |

#### 策略 3：止盈止損

| 項目 | 說明 |
|------|------|
| **類型** | 風控 |
| **買入** | — |
| **賣出** | 虧損達 X% 止損、獲利達 Y% 止盈 |
| **參數** | 止損 %（如 -10）、止盈 %（如 20） |
| **優點** | 控制單筆虧損、鎖定獲利 |
| **缺點** | 可能過早出場或錯過大行情 |
| **適用** | 搭配任何買入策略 |
| **程式** | `strategy.check_stop_loss()`、`strategy.check_take_profit()` |

#### 策略 4：均線交叉

| 項目 | 說明 |
|------|------|
| **類型** | 趨勢跟隨 |
| **買入** | 短期 MA（如 5 週）上穿長期 MA（如 20 週） |
| **賣出** | 短期 MA 下穿長期 MA |
| **參數** | 短期週期、長期週期 |
| **優點** | 訊號明確、易回測 |
| **缺點** | 震盪市假訊號多 |
| **適用** | 趨勢明顯的標的 |

#### 策略 5：RSI 超買超賣

| 項目 | 說明 |
|------|------|
| **類型** | 均值回歸 |
| **買入** | RSI < 30（超賣） |
| **賣出** | RSI > 70（超買） |
| **參數** | RSI 週期（通常 14）、門檻 30/70 |
| **優點** | 逆勢抄底、適合區間 |
| **缺點** | 強趨勢中易提早進出 |
| **適用** | 區間震盪的標的 |

#### 策略 6：布林帶

| 項目 | 說明 |
|------|------|
| **類型** | 均值回歸 |
| **買入** | 價格觸及下軌（或跌破後回升） |
| **賣出** | 價格觸及上軌（或突破後回落） |
| **參數** | 均線週期、標準差倍數（通常 2） |
| **優點** | 視覺化、波動自適應 |
| **缺點** | 趨勢市可能連續觸軌 |
| **適用** | 區間震盪 |

#### 策略 7：動量突破

| 項目 | 說明 |
|------|------|
| **類型** | 趨勢跟隨 |
| **買入** | 收盤價突破過去 N 日最高價 |
| **賣出** | 收盤價跌破過去 N 日最低價 |
| **參數** | N（如 20、55） |
| **優點** | 捕捉突破、順勢 |
| **缺點** | 假突破多、需嚴格止損 |
| **適用** | 波動大、趨勢明確的標的 |

#### 策略 8：價值平均

| 項目 | 說明 |
|------|------|
| **類型** | 被動累積 |
| **買入** | 每期目標市值 = 上期 × (1+成長率)；若現值 < 目標，買入差額 |
| **賣出** | 若現值 > 目標，賣出多餘部分（或僅買不賣） |
| **參數** | 週期、每期成長率、目標市值 |
| **優點** | 下跌多買、上漲少買，紀律化 |
| **缺點** | 大跌時需較多資金 |
| **適用** | 長期累積、有明確目標 |

#### 策略 9：DCA + 均線過濾

| 項目 | 說明 |
|------|------|
| **類型** | 混合（被動 + 趨勢） |
| **買入** | 固定週期檢查；僅當價格 > 均線時才執行 DCA |
| **賣出** | 止盈止損 |
| **參數** | 週期、單筆金額、均線週期 |
| **優點** | 減少下跌段加碼、保留 DCA 紀律 |
| **缺點** | 可能錯過低點加碼 |
| **適用** | 想降低下跌加碼心理壓力時 |

#### 策略 10：網格交易

| 項目 | 說明 |
|------|------|
| **類型** | 區間 |
| **買入** | 價格每下跌 X% 買一檔固定金額 |
| **賣出** | 價格每上漲 X% 賣出對應檔位 |
| **參數** | 網格間距 %、每格金額、區間上下限 |
| **優點** | 區間震盪可反覆獲利 |
| **缺點** | 單邊趨勢可能破網或套牢 |
| **適用** | 區間明確的標的（如部分 ETF） |

### 1.3 策略選擇建議

| 情境 | 建議策略 |
|------|----------|
| 長期看好、不想擇時 | 策略 2 DCA |
| 想順勢、減少假訊號 | 策略 1 均線偏離、策略 4 均線交叉 |
| 區間震盪、想抄底 | 策略 5 RSI、策略 6 布林帶 |
| 強勢突破 | 策略 7 動量 |
| 控制風險 | 策略 3 止盈止損（必備） |
| 下跌不想加碼太多 | 策略 9 DCA+均線過濾 |

### 1.4 低頻管理＋保留現金：適合策略

> 若**一週看盤一次、一個月總結一次**，且希望**保持現金倉位**，建議以下組合。

#### 1.4.1 推薦策略組合

| 策略 | 頻率 | 說明 |
|------|------|------|
| **DCA 定額定投** | 每月 1 次 | 固定日期投入固定金額，不需擇時 |
| **止盈止損** | 每週檢查 1 次 | 持倉虧/賺達門檻時平倉，控制風險 |
| **現金比例規則** | 每月檢視 | 維持現金 ≥ 總資產 X%（如 20–30%） |

#### 1.4.2 操作節奏建議

| 頻率 | 動作 |
|------|------|
| **每週 1 次**（約 5–10 分鐘） | 看持倉、檢查是否觸及止盈止損、必要時平倉 |
| **每月 1 次**（約 30 分鐘） | 執行 DCA 買入、檢視現金比例、做當月總結 |

#### 1.4.3 現金倉位規則

| 規則 | 說明 |
|------|------|
| **最低現金比例** | 建議保留總資產 20–30% 現金，大跌時可加碼 |
| **DCA 金額** | 每月投入金額 ≤ (總資產 × 目標股票比例) / 12，避免過度投入 |
| **單筆上限** | 單次 DCA 不超過月收入可投資部分，維持生活現金流 |

#### 1.4.4 不建議的策略（需高頻管理）

| 策略 | 原因 |
|------|------|
| RSI、布林帶 | 訊號較頻繁，需較常看盤 |
| 網格交易 | 價格變動時需多次買賣 |
| 動量突破 | 突破後宜盡快進場 |
| 均線交叉（短週期） | 若用日線需較常檢查 |

#### 1.4.5 簡化執行範例

```
每月第 1 個交易日：
  1. 檢查現金比例，若 > 30% 則執行 DCA（買入預定標的、預定金額）
  2. 若現金 < 20%，當月暫停 DCA

每週五（或固定日）：
  1. 開啟 eToro 或程式，檢查持倉
  2. 若有持倉虧損 ≥ 10%，考慮止損
  3. 若有持倉獲利 ≥ 20%，考慮止盈（或分批）
  4. 無觸及則不動作
```

## 二、手續費制度（eToro）

### 2.1 股票

| 項目 | 說明 |
|------|------|
| **手續費** | 固定 **$1 美金／筆**（買、賣各 $1） |
| **來回成本** | 買 + 賣 = **$2** |
| **對 DCA 影響** | 單筆小則佔比高，建議股票僅大筆（≥ $500） |

### 2.2 ETF

| 項目 | 說明 |
|------|------|
| **手續費** | 可能**免開倉費**（依標的，下單前確認「估計的開立費用」） |
| **對 DCA 影響** | 適合 DCA，可多筆、多檔 |

### 2.3 加密貨幣

| 項目 | 說明 |
|------|------|
| **計費方式** | 點差約 0.75%–4.5%（依幣種），非 $1/筆 |
| **對 DCA 影響** | 適合 DCA，與股票計費不同 |

## 三、下單金額規則

### 3.1 手續費佔比參考

| 單筆金額 | 來回手續費 | 手續費佔比 |
|----------|------------|------------|
| $100     | $2         | 2.0%       |
| $200     | $2         | 1.0%       |
| $300     | $2         | 0.67%      |
| $500     | $2         | 0.4%       |
| $1,000   | $2         | 0.2%       |

### 3.2 建議單筆金額

| 情境 | 建議單筆 | 說明 |
|------|----------|------|
| **最低門檻** | $200 | 來回約 1%，勉強可接受 |
| **較佳** | $300–500 | 來回約 0.4–0.67% |
| **理想** | $500+ | 來回約 0.4% 以下 |

### 3.3 依資金規模（假設總資金約 $50,000）

| 情境 | 建議單筆 |
|------|----------|
| 新建倉 | $400–500 |
| 加碼既有倉位 | $300–400 |
| 測試新標的 | $200–300 |

### 3.4 實務原則

1. **股票**：單筆 ≥ $500，減少檔數與筆數（eToro $1/筆不適合股票 DCA）
2. **ETF**：可能免手續費，可多檔 DCA
3. **加密貨幣**：點差計費，可 DCA
4. **策略方向**：股票大筆、減倉後轉 ETF + 加密貨幣為主（台灣入金 eToro 較方便）

## 八、基本面與估值數據（訂單量、營收、市值）

> eToro API **不提供**基本面數據。以下數據需透過外部來源取得，供估值與策略決策參考。

### 8.1 數據類型與用途

| 數據類型 | 說明 | 策略用途 | 取得難度 |
|----------|------|----------|----------|
| **股價** | 當前價 | 與 eToro 即時價對照 | eToro 有 |
| **市值** | 股價 × 流通股數 | 估值規模、比較 | 外部 API |
| **營收** | 季度／年度營收 | 營收能力 | 財報、API |
| **營收增長** | YoY 同比增長 | 成長性判斷 | 財報、API |
| **訂單量／訂單 backlog** | 半導體：晶片訂單、AI 基建訂單 | 需求能見度 | 財報、新聞 |
| **交付量** | 出貨量、單位數 | 供給與需求匹配 | 財報、新聞 |
| **P/E、P/S** | 本益比、市銷比 | 估值貴賤 | 外部 API |

### 8.2 數據來源

| 來源 | 說明 | 取得方式 |
|------|------|----------|
| **eToro** | 股價、K 線 | 已有 API |
| **財報／法說** | 營收、訂單、交付量 | 公司 IR、SEC EDGAR |
| **Financial Modeling Prep** | 營收、市值、財報 | 免費 API key，`fetch_fundamentals.py` |
| **Alpha Vantage** | 基本面、財報 | 免費 API key |
| **手動整理** | 訂單量、交付量（如 NVDA、AMD 等） | 見 8.4 節 |

### 8.3 策略整合邏輯（供參考）

```
估值參考流程：
  1. 取得：股價、市值、營收、營收增長率
  2. 計算：P/S、營收增長率
  3. 過濾：營收增長 > 門檻 且 P/S 在合理區間 → 可考慮加碼
  4. 結合：20 週均線訊號 + 估值過濾 → 最終買訊
```

### 8.4 低頻估值測算（適合每月檢查一次）

> 用既有數據（`fundamentals.json`）做簡單估值判斷，不需複雜模型。每月執行 `fetch_fundamentals` 後套用即可。

#### 8.4.1 適用情境

- 一週看盤一次、一個月總結一次
- 用 P/E、P/S、營收增長等既有欄位
- 產出「貴／合理／便宜」或「可加碼／觀望／暫緩」

#### 8.4.2 簡易估值規則（依公司類型）

| 類型 | 條件 | 解讀 |
|------|------|------|
| **成熟型**（有穩定獲利） | P/E < 15 | 便宜 |
| | P/E 15～25 | 合理 |
| | P/E > 25 | 偏貴（除非高成長） |
| **成長型**（營收高增長） | P/S < 5 且 營收增長 > 20% | 可考慮 |
| | P/S 5～15 且 營收增長 > 15% | 觀望 |
| | P/S > 15 或 營收增長 < 10% | 暫緩加碼 |
| **PEG 概念**（有獲利＋成長） | P/E ÷ 營收增長% < 1.5 | 估值尚可 |
| | P/E ÷ 營收增長% > 2 | 偏貴 |

*營收增長%：如 0.15 視為 15%*

#### 8.4.3 每月操作流程

```
1. 執行 python -m etoro_trading.scripts.fetch_fundamentals
2. 執行 python -m etoro_trading.scripts.calc_valuation_simple（產出貴/合理/便宜）
3. 或開啟 fundamentals.json、整合總表 Excel 手動對照 8.4.2 規則
4. DCA 時：優先買「合理」或「便宜」；「貴」或「暫緩」的標的當月可減量或跳過
```

| UNH | 22 | 0.6 | 7.7% | 成熟型，合理 |
| ACN | 17 | 1.8 | 7.4% | 成熟型，合理 |
| IBM | 22 | 3.5 | 1.4% | 成熟型，合理 |
| CRM | 26 | 4.4 | 8.7% | 成熟型，略貴 |
| NVDA | 37 | 21 | 65.5% | 成長型，P/S 高但增長強，觀望 |
