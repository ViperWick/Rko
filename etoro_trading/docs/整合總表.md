| 項目 | 設定 |

| 類型 | 策略 |

## 六、分散板塊（與科技相關性低）

> 供分散配置參考。公用事業、消費必需品、能源與科技股相關性低。

### 6.1 產業與科技相關性

| 產業 | 與科技相關性 | 說明 |
|------|:------------:|------|
| 公用事業 | 低～負 | 最佳分散板塊 |
| 能源 | 低 | 2024 後分散效果提升 |
| 消費必需品 | 低～中 | 防禦型 |
| 醫療 | 中 | 已有 UNH，分散尚可 |
| 黃金 | 低 | 已有 GLD |

### 6.2 分散板塊標的清單

| 產業 | 標的 | 類型 | 說明 |
|------|------|:----:|------|
| **公用事業** | NEE, SO, DUK, XEL, AEP, SRE, XLU | 股×6、ETF×1 | 與科技相關性最低 |
| **消費必需品** | KO, PEP, WMT, PG, JNJ, XLP | 股×5、ETF×1 | 防禦型 |
| **能源** | XOM, CVX, XLE | 股×2、ETF×1 | 與科技不同週期 |
| **醫療** | UNH, JNJ, XLV | 股×2、ETF×1 | 已有 UNH |

### 6.3 建議分散配置優先順序

| 優先 | 標的 | 產業 | 理由 |
|:----:|------|------|------|
| 1 | NEE | 公用事業 | 與科技相關性最低 |
| 2 | XLU | 公用事業 ETF | 一檔涵蓋板塊 |
| 3 | KO 或 PEP | 消費必需品 | 防禦型 |
| 4 | XLE | 能源 ETF | 能源分散 |
| 5 | WMT | 消費必需品 | 大型零售 |

## 七、匯出 Excel / Word

執行以下指令可匯出為 Excel 或 Word：

```powershell
# 預設：匯出 Excel
python -m etoro_trading.scripts.export_integrated_table

# 僅匯出 Word
python -m etoro_trading.scripts.export_integrated_table --word

# 同時匯出 Excel 與 Word
python -m etoro_trading.scripts.export_integrated_table --all
```

**輸出檔案**：
- `etoro_trading/data/整合總表.xlsx`（多分頁：名單總覽、標的完整資訊、策略與規則、分散建議、不建議納入）
- `etoro_trading/data/整合總表.docx`
