# 世界模型 — 螺旋週期 × 均值回歸 × 納什均衡

## 快速開始

**雙擊 `run.bat`** 即可執行所有範例。

## 首次設定

若 `conda` 或 `python` 無法辨識，請執行：

```powershell
powershell -ExecutionPolicy Bypass -File "setup_env.ps1"
```

執行後**重新開啟終端**，PATH 即會生效。

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `run.bat` | 雙擊執行範例 |
| `run_world_model.py` | 範例啟動器 |
| `setup_env.ps1` | 將 Miniconda 加入 PATH、安裝依賴 |
| `世界模型/` | 核心程式與理論架構 |
