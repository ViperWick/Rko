# 世界模型 — 使用說明

## 一鍵執行

在專案根目錄 `C:\Users\User\.cursor-tutor` 下：

- **雙擊 `run.bat`** 即可執行所有範例
- 或在終端執行：`python run_world_model.py`

## 首次設定（若 conda/python 無法使用）

在 PowerShell 執行：

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\User\.cursor-tutor\setup_env.ps1"
```

執行後**關閉並重新開啟終端**，PATH 才會生效。

## 檔案結構

```
世界模型/
├── run_ui.bat           # 雙擊啟動統一城市 UI（唯一啟動方式）
├── world_model.py       # 核心模型
├── city_model.py        # 統一城市模型
├── app.py               # Streamlit UI 介面
├── examples.py          # 應用範例
├── requirements.txt    # 依賴套件
├── README_理論架構.md
└── 使用說明.md          # 本檔
```

## 統一城市 UI

在 **世界模型** 資料夾內：

- **雙擊 `run_ui.bat`** 即可啟動 Streamlit 介面

首次使用請先安裝依賴：`pip install -r requirements.txt`

## 輸出

執行 `run.bat` 後會在 `世界模型/` 目錄產生：

- `example_economic.png` — 經濟景氣與股價圖
- `example_integrated.png` — 整合模型模擬圖
