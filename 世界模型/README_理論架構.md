# 螺旋週期 × 均值回歸 × 納什均衡 — 通用世界模型

> 一個可應用於世界上任何事物的整合框架

---

## 一、三大支柱

### 1. 螺旋週期 (Spiral Cycle)

**定義**：事物並非簡單循環，而是螺旋式演進——每次「回歸」都帶有新的層次。

```
         ↗ 更高層次
        /
    ●——●  每圈相似但不同
   /    \
  ●      ●  時間軸上的演進
   \    /
    ●——●
```

**特徵**：
- 週期性：模式會重複出現
- 演進性：每次循環在更高/不同維度
- 適用：經濟週期、季節、情緒波動、技術迭代

---

### 2. 均值回歸 (Mean Reversion)

**定義**：偏離長期均衡的變量，有向中心回拉的傾向。

```
  偏離 ↑
       |    ●
       |   /  \  回歸力
均值 ——●——●——●——●——●——  時間
       |   \  /
       |    ●
  偏離 ↓
```

**特徵**：
- 均衡點：長期平均 / 自然水平
- 回歸力：偏離越大，拉力越強（可類比彈簧）
- 適用：價格、溫度、情緒、人口、資源

---

### 3. 納什均衡 (Nash Equilibrium)

**定義**：多方博弈中，無人能透過單方面改變策略而獲益的穩定狀態。

```
    玩家B
    策略1  策略2
A 策略1  (3,3)  (0,5)   → 雙方都選策略1 = 納什均衡
B 策略2  (5,0)  (1,1)
```

**特徵**：
- 多方互動：至少兩個決策主體
- 策略依賴：我的最佳選擇取決於你的選擇
- 穩定點：無人想單獨偏離
- 適用：市場競爭、國際關係、人際互動、生態系統

---

## 二、整合模型：三維世界觀

```
                    【螺旋週期】
                    時間維度
                         ↗
                        /
                       /
    【均值回歸】 ←—— ● ——→ 【納什均衡】
    統計維度              策略維度
```

### 整合邏輯

| 維度 | 回答的問題 | 核心機制 |
|------|------------|----------|
| **螺旋週期** | 事物如何隨時間演進？ | 週期 + 層次演進 |
| **均值回歸** | 事物的自然平衡點在哪？ | 偏離 → 回拉 |
| **納什均衡** | 多方互動如何達到穩定？ | 策略最優回應 |

### 統一公式（概念層）

```
世界狀態(t) = f(
    螺旋相位(週期, 層次),
    偏離均值的程度,
    各方的策略組合
)
```

## 三、應用領域速查

| 領域 | 螺旋週期 | 均值回歸 | 納什均衡 |
|------|----------|----------|----------|
| **經濟** | 景氣循環、泡沫週期 | 股價、匯率、利率 | 市場競爭、寡占定價 |
| **政治** | 政權輪替、意識形態擺盪 | 權力集中度、民調 | 國際博弈、聯盟形成 |
| **社會** | 世代價值觀、流行週期 | 不平等程度、犯罪率 | 社會規範、集體行動 |
| **個人** | 情緒週期、學習曲線 | 健康指標、習慣強度 | 人際關係、職場博弈 |
| **自然** | 季節、太陽黑子 | 生態承載量、物種數量 | 物種競爭、共生演化 |
| **科技** | 技術成熟度曲線、創新浪潮 | 採用率、標準化程度 | 平台競爭、標準戰爭 |

---

## 四、使用指南

1. **單一現象**：先問「有週期嗎？」→ 用螺旋週期；再問「有均衡點嗎？」→ 用均值回歸
2. **多方互動**：辨識決策者 → 建立報酬矩陣 → 尋找納什均衡
3. **複雜系統**：三者疊加——在時間螺旋中，各方博弈趨向均衡，而均衡點本身可能均值回歸
