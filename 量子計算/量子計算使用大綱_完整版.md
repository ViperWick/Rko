### 1.2 量子疊加與RF相位

🌊 量子疊加態

• 就像兩個RF信號的相干疊加
• 相位差決定干涉圖案
• 測量 = 檢測最終的RF信號強度

### 1.3 量子糾纏與RF耦合

🔗 量子糾纏
兩個量子比特的狀態完全相關

📡 RF工程師的類比
• 就像兩個耦合的RF振盪器
• 強耦合 → 同步振盪
• 弱耦合 → 獨立振盪

### 1.4 量子閘門與RF脈衝

🎛️ 量子閘門操作

## 量子計算基礎理論

### 量子比特 (Qubit) 的物理實現

#### 超導量子比特
- **Josephson結**：超導量子比特的核心元件
- **共振頻率**：通常在4-8 GHz範圍
- **控制方式**：微波脈衝精確控制
- **測量方式**：高靈敏度RF讀取

#### 離子阱量子比特
- **物理原理**：利用電磁阱捕獲離子
- **控制方式**：激光和RF場結合
- **優勢**：高保真度，長相干時間
- **挑戰**：系統複雜度高

### 量子疊加與干涉

#### 數學描述
```
|ψ⟩ = α|0⟩ + β|1⟩
```
其中：
- α, β 是複數振幅
- |α|² + |β|² = 1 (歸一化條件)
- |α|² 是測量到|0⟩的機率
- |β|² 是測量到|1⟩的機率

#### RF工程師的類比
- **相位表示**：|0⟩ = 0°, |1⟩ = 180°
- **疊加態**：|+⟩ = 0° + 180° = 90°
- **干涉效應**：類似RF信號的相干疊加
- **測量過程**：類似RF功率檢測

### 量子糾纏

#### 物理機制
兩個量子比特的狀態完全相關，測量一個會瞬間確定另一個的狀態。

#### 數學表示
```
|Φ⁺⟩ = (|00⟩ + |11⟩)/√2
```

#### RF系統的類比
- **耦合振盪器**：兩個RF振盪器的強耦合
- **同步現象**：類似鎖相環的相位同步
- **關鍵差異**：量子糾纏具有非局域性

## RF與量子計算的技術橋樑

### 控制系統架構

#### 量子控制系統組成
```
主控制器 → 微波合成器 → 放大器 → 濾波器 → 量子比特
    ↓
數據採集 ← ADC ← 放大器 ← 濾波器 ← 讀取線
```

#### RF工程師的專業優勢
- **微波設計**：熟悉GHz頻段的電路設計
- **低噪聲設計**：量子級噪聲要求
- **相位控制**：精確的相位調製技術
- **系統整合**：複雜RF系統的整合經驗

### 量子閘門的RF實現

#### X閘門 (Pauli-X)
- **物理實現**：π脈衝
- **RF要求**：
  - 脈衝寬度：~20ns
  - 頻率穩定度：<1 ppb
  - 相位噪聲：<-120 dBc/Hz @ 1kHz offset

#### Y閘門 (Pauli-Y)
- **物理實現**：π/2脈衝 + 90°相位偏移
- **RF挑戰**：精確的相位控制

#### Z閘門 (Pauli-Z)
- **物理實現**：頻率調製或虛擬Z閘
- **RF優勢**：不需要額外的微波功率

#### H閘門 (Hadamard)
- **物理實現**：π/2脈衝序列
- **RF複雜度**：多脈衝的精確時序控制

### 量子測量系統

#### 讀取電路設計
```
量子比特 → 讀取諧振器 → 傳輸線 → 低噪聲放大器 → 混頻器 → ADC
```

#### 關鍵參數
- **讀取頻率**：6-7 GHz
- **讀取功率**：-120 dBm (避免量子比特激發)
- **放大器噪聲**：<0.5 K (量子極限附近)
- **採樣率**：100 MS/s (實時反饋需求)

## 操作指南

#### 1. 電路構建器使用
```
左側面板 → 拖拽閘門 → 放置到量子位元線 → 執行電路
```

#### 2. 量子閘門類型
- **X閘門** 🟠：量子翻轉操作（類似RF的180°相位反轉）
- **H閘門** 🟣：Hadamard閘（創造疊加態，類似RF的90°相位偏移）
- **Z閘門** 🔵：相位閘門（改變相位，類似RF的相位調製）

#### 3. 電路操作
- **拖拽放置**：從左側面板拖拽閘門到量子位元線
- **雙擊移除**：雙擊電路上的閘門可移除
- **執行電路**：點擊「▶️ 執行電路」查看結果
- **重置電路**：點擊「🔄 重置」清空所有閘門

- **實時更新**：電路序列會即時更新
