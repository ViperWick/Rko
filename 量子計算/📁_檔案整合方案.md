# 📁 量子計算資料夾整合方案

## 🎯 整合目標
將所有量子計算相關檔案按照功能分為三種類型：
1. **PPT生成程式** - 自動生成簡報的工具
2. **HTML遊戲** - 互動式量子計算學習遊戲
3. **使用大綱** - 說明文件和教學資源

---

## 📊 第一類：PPT生成程式

### 核心檔案
```
📁 PPT生成工具/
├── 🐍 量子計算介紹PPT_RF專業版.py
├── 🐍 量子計算PPT_簡化版.py
├── 🐍 generate_quantum_ppt.py
├── 🐍 generate_quantum_ppt_for_boss.py
└── 📋 PPT生成說明.md
```

### 功能說明
- **量子計算介紹PPT_RF專業版.py**: 完整版PPT生成器，包含RF專業背景內容
- **量子計算PPT_簡化版.py**: 簡化版PPT生成器，不依賴外部庫
- **generate_quantum_ppt.py**: 通用PPT生成器
- **generate_quantum_ppt_for_boss.py**: 老闆專用版本

### 使用方式
```bash
# 運行完整版PPT生成器
python 量子計算介紹PPT_RF專業版.py

# 運行簡化版PPT生成器
python 量子計算PPT_簡化版.py
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
量子計算資料夾整合工具
"""

import os
import shutil

def organize_quantum_files():
    """整理量子計算檔案"""
    
    # 創建分類資料夾
    folders = {
        'PPT生成程式': [],
        'HTML遊戲': [],
        '使用大綱': []
    }
    
    # 檔案分類規則
    ppt_files = [
        '量子計算介紹PPT_RF專業版.py',
        '量子計算PPT_簡化版.py',
        'generate_quantum_ppt.py',
        'generate_quantum_ppt_for_boss.py'
    ]
    
    html_files = [
        '量子謎題12關_Alice冒險版.html',
        '量子計算12關遊戲.html',
        '量子謎題_視覺升級版.html',
        '量子計算介紹.html',
        '量子計算與股票市場分析.html',
        '功能預覽示例.html'
    ]
    
    outline_files = [
        '量子計算PPT_內容大綱.md',
        '量子計算演講腳本.md',
        '量子計算專業文本_RF工程師指南.md',
        '量子計算小遊戲_使用指南.md',
        '更新日誌_詳細講解版.md',
        '詳細講解功能說明.txt',
        '使用說明_郵件分享版.txt',
        '郵件範本.txt',
        '發送前檢查清單.txt',
        '完整資源總覽.txt'
    ]
    
    return {
        'PPT生成程式': ppt_files,
        'HTML遊戲': html_files,
        '使用大綱': outline_files
    }

if __name__ == "__main__":
    files = organize_quantum_files()
    for category, file_list in files.items():
        print(f"📁 {category}:")
        for file in file_list:
            print(f"   📄 {file}")
        print()
```
