# 每週市場與能源檢查表

固定每週用一次，快速回答三件事：**利率／美元／風險胃納**、**風險資金大致往哪流**、**電力與核能敘事是否變強**。數字以你執行當下的官方來源為準；本表提供查詢點與判讀框架。

---

## 一、給我的「一鍵指令」（貼在對話即可）

把下面整段複製到 Cursor 對話，把日期改成本週即可：

```text
請依「每週市場與能源檢查表」幫我做本週快照（只上網查最新可得，並附出處連結）：

1) 宏觀：美國 10 年期公債殖利率（FRED DGS10 或同等）、廣義美元（FRED DTWEXBGS 或 DXY 行情）、美國高收益債 OAS（FRED BAMLH0A0HYM2）
2) 風險資金：美國現貨比特幣 ETF 近 5 個交易日淨流＋本週合計（若可得）；全球或美股主要股票 ETF 週淨流趨勢一句話（若可得）
3) 能源與電力：美國發電量燃料占比最新月（EIA Electricity）；必要時補 EIA Nuclear（停機／發電量）或天然氣價一句話
4) 核能進展（集中三句，見本檔第八節）：IAEA PRIS 全球在建或商轉有無變化；EIA 美國核能停機／發電是否異常；WNA 或主要監管機構一則政策／建案事實（勿只報股價）
5) 用 5 行內總結：風險偏好上／下？美元偏緊／鬆？信用偏鬆／緊？核能線索是「機組＋發電事實」變強還是僅市場敘事？

若某項查不到，請明說缺什麼資料源，不要猜數字。
```

## 三、本機程式（可選）

目錄內 `run_weekly_snapshot.py`：

- **FRED**：一次拉最近幾筆 **`DGS10`、`DTWEXBGS`、`BAMLH0A0HYM2`**（需 [FRED API Key](https://fred.stlouisfed.org/docs/api/api_key.html)）。


若未設定 `FRED_API_KEY`，會略過 FRED 並印連結；若未設定 `EIA_API_KEY`，會略過 EIA 測試。

## 四、判讀備忘（避免過度解讀）

- **單週資金流**噪音大；以 **4 週移動**或 **月合計** 輔助。  
- **核能是否為主**：要看 **發電量＋在建＋政策預算**，股價與敘事僅供輔助。  
- **能源 vs 科技同漲**：可能是同一套「電力需求／風險偏好」敘事，不代表永遠高相關。

## 五、數據用途說明：腳本裡每一項「能幹嘛」

以下是你現在 **一鍵執行腳本** 會看到的欄位；用途是 **觀察宏觀環境與風險偏好**，不是預測單一資產漲跌。

| 代碼／項目 | 是什麼 | 能幫你判斷什麼 | 常見搭配讀法 |
|------------|--------|----------------|--------------|
| **FRED `DGS10`** | 美國 10 年期公債殖利率（名目） | **長天期利率水準**：偏高常壓「久期長」的資產估值（成長股、長債）；快速上行常伴波動放大 | 搭配聯準會路徑、通膨預期新聞；與 `TLT` 價格反向看 |
| **FRED `DTWEXBGS`** | 美國 **廣義**貿易加權美元指數（商品＋服務） | **全球金融條件**一環：偏強常與「美元流動性緊、新興市場承壓」同方向討論（非每日一對一） | 與金價、新興 ETF、原物料同週對照；**不是**期貨 `DXY`，數值不可混比 |
| **FRED `BAMLH0A0HYM2`** | 美國高收益公司債 **OAS**（選擇權調整後利差） | **信用風險／風險胃納**：利差 **擴大** → 市場對違約與流動性較擔憂；**收窄** → 偏願意承擔風險（仍可能有滯後） | 與股市大跌、油價衝擊、財報季同看 |
| **EIA `RWTC`（WTI 現貨）** | 美國 WTI 原油 **日頻** 現貨價 | **油價水準**：影響通膨預期、能源股、運輸成本敘事；腳本裡主要用來 **驗證 EIA API 金鑰有效** | 若要「發電燃料結構」必須改查 **Electricity** 類路由，見下文 |

**一句話**：前三項偏 **「股債商定價的背景」**；EIA 這一筆偏 **「能源價格水位＋API 是否正常」**。

## 六、還能取得哪些資料？（FRED／EIA／手動）

### 6.1 FRED（同一支金鑰，換 `series_id` 即可擴充）

在 [FRED 搜尋](https://fred.stlouisfed.org/) 找系列 ID，常與本表主題相關的例子：

| 系列（示例） | 大致用途 |
|--------------|----------|
| `T10YIE` | 10 年期 **盈虧平衡通膨**（市場對通膨的定價之一） |
| `T10Y2Y` | 10 年與 2 年殖利率利差（曲線斜率／衰退討論常引用） |
| `VIXCLS` | 恐慌指數（股權波動） |
| `NFCI` | 芝加哥聯準 **全國金融狀況指數**（緊／鬆） |
| `WALCL` | 聯準會資產負債表規模（寬鬆／收水大方向） |

若要加進腳本：在 `run_weekly_snapshot.py` 的 `SERIES` 列表依樣增加 `(id, 中文說明)` 即可（仍建議每週人工解讀，不要過度自動化交易）。

### 6.2 EIA Open Data API v2（同一支金鑰，換 **路由 route**）

你在 **API Dashboard** 下拉選的 **Coal / Electricity / Natural Gas / Petroleum…** 都是 **同一支 API Key** 底下的不同路徑。常見用途：

| 類別 | 你能拿來做什麼 |
|------|----------------|
| **Electricity** | 美國 **發電量、燃料組合、零售電價、RTO 區域** 等（最貼近「核 vs 燃氣 vs 風光」實際占比） |
| **Petroleum** | 原油、成品油、庫存、進出口、**WTI／Brent 價格**（腳本範例用 WTI） |
| **Natural Gas** | 氣價、庫存、發電與工業需求線索（美國氣電占比高時很重要） |
| **Coal / Total energy / STEO** | 煤與總能源、**官方展望（STEO）** 等中長線假設與預測表 |

**實務建議**：到 [API Dashboard / Browse](https://www.eia.gov/opendata/browser/) 選好篩選後，用畫面上的 **「API」按鈕** 複製完整 URL，再把那段路徑寫進自己的 Python（或貼給我幫你併進 `run_weekly_snapshot.py`）。

## 七、指標規格（Spec）與「區間」代表什麼（務必搭配趨勢讀）

### 7.0 先講清楚：什麼是「事實」、什麼是「解讀」

| 層次 | 內容 |
|------|------|
| **事實** | 官方或交易所公布的 **數字與定義**（例如「某日 DGS10 收在 4.40%」）。 |
| **解讀** | 市場常把某些區間稱為「偏鬆／偏緊」，那是 **歷史經驗＋敘事**，會隨 **通膨 regime、央行框架、地緣** 改寫，**不是自然定律**。 |
| **建議讀法** | 同一指標看三件事：**① 最近 5～20 個交易日的方向**、**② 近一年分位（高／中／低）**、**③ 與信用／股市／油價是否同週共振**。 |

以下「區間」均以 **美國宏觀與 2020 年代常見區間** 為口述參考；跨年代比較請用 **分位數** 而非死記數字。

---

### 7.1 FRED `DGS10`（美國 10 年期公債殖利率）

| 項目 | 說明 |
|------|------|
| **單位** | **百分比（%）**，年化名目殖利率。 |
| **本質** | 市場對 **未來十年名目利率與成長／通膨** 的綜合定價之一（還受期限溢價、供需影響）。 |
| **「偏低」常見敘事（示意）** | 約 **< 2.5%**：多對應 **極寬鬆或避險** 時段（例如疫情初期、長期接近零利率年代）；**2.5%～3.5%**：常見「偏寬鬆～中性」討論區（仍看同時的通膨與政策）。 |
| **「中性～偏緊」常見敘事（示意）** | 約 **3.5%～4.5%**：2023 年以後常被討論為 **「限制性利率存在」**；**> 4.5%～5%**：偏 **高名目利率** 區，常與「壓估值／壓久期」「財政供給」等敘事並列討論。 |
| **「快速變化」本身** | **幾天內上下 10bp 以上**：常代表 **資料、拍賣、聯準會官員談話、就業／CPI** 等事件正在被定價；**慢牛爬升**：有時是「成長韌性」或「供給」故事。 |
| **不能單獨推論的** | 殖利率高 **不等於** 股市一定跌（還要看盈餘、風險偏好、資金流）。 |

---

### 7.2 FRED `DTWEXBGS`（廣義貿易加權美元指數）

| 項目 | 說明 |
|------|------|
| **單位** | **指數（index）**，不是百分比；FRED 定義為對 **多國貨幣廣義加權**（含商品與服務貿易權重），**與期貨 `DXY` 成分與基期不同，數值不可直接互換比較**。 |
| **本質** | 美元相對一籃子貨幣 **偏強或偏弱** 的統計結果。 |
| **怎麼讀「區間」才對** | **沒有**「大於某數就一定是壞事」的通用規則；正確用法是：**與自己過去 52 週區間比**（例如是否接近週區間上緣）、**與 3 個月前比**。 |
| **「走強」常見連動敘事（示意）** | 若 **同週** 看到新興市場承壓、原物料美元計價偏弱、跨國資金回流美國等，常一起被敘事化為 **「全球金融條件偏緊」**（仍非定律）。 |
| **「走弱」常見連動敘事（示意）** | 風險偏好回升、美元資金外流敘事、或主要非美貨幣反彈時段。 |
| **不能單獨推論的** | 美元指數與 **美股漲跌** 沒有固定正負相關，要看當時主導因子是「成長」還是「流動性」。 |

---

### 7.3 FRED `BAMLH0A0HYM2`（美國高收益債 OAS）

| 項目 | 說明 |
|------|------|
| **單位** | **百分比（%）**，為 **利差（spread）**，不是價格。 |
| **本質** | 市場要求非投資等級債多承擔的 **信用＋流動性溢價** 粗略指標之一（仍受產業組成、存續期影響）。 |
| **「偏窄」常見敘事（示意）** | 約 **< 3.0%～3.2%**：常描述為 **利差偏緊、風險胃納偏樂觀**；極窄時市場也會討論 **「報酬補償不足／自滿」**（這是風險討論，不是預言）。 |
| **「中性」常見敘事（示意）** | 約 **3.0%～4.0%**：常見「有風險定價但不失控」區間；**邊際變化**（一週擴 10～20bp）有時比絕對水位更受關注。 |
| **「偏寬」常見敘事（示意）** | 約 **> 4.5%～5%**：常開始出現 **「信用事件／衰退擔憂」** 類討論；**> 6%～8%**（歷史上重大壓力時段曾出現更高）：多與 **流動性乾涸、大級別违约擔憂** 並列討論（每次危機口徑不同）。 |
| **「快速擴大」** | 短天內 **顯著走寬**：常代表 **企業违约預期、基金赎回、風險資產去槓桿** 之一或組合正在上調。 |
| **不能單獨推論的** | OAS 窄 **不代表** 不會跌；寬 **不代表** 立刻進場就賺。 |

---

### 7.4 EIA WTI 現貨 `RWTC`（美元／桶）

| 項目 | 說明 |
|------|------|
| **單位** | **美元／桶**，日頻現貨（腳本取最近幾個交易日）。 |
| **本質** | 全球供需、地緣、庫存、金融條件對 **油價** 的綜合結果；在腳本裡 **主要作 EIA API 連線驗證**，兼看油價水位。 |
| **「區間」敘事（極粗示意）** | **< 50**：常見「供給寬鬆或需求擔憂」討論區之一；**50～80**：歷史上常見的「中段震盪」敘事區（依年代變動）；**> 90～100**：常與 **地緣溢價、供給不確定** 並列討論（非精確門檻）。 |
| **「急漲／急跌」** | 常與 **OPEC+、戰爭風險、煉廠事故、金融去槓桿** 等事件同一週發生；應回頭找 **原因** 而非只解讀數字。 |
| **與核能敘事的關係** | 油價是 **能源價格與通膨預期** 的一環；**不能直接推出**「核能占比會變高」，只能說 **能源安全與電力成本** 討論容易升溫。 |

### 7.5 若你擴充 FRED 系列時，可參考的讀法（簡表）

| 系列（示例） | 單位／型態 | 區間或變化常見解讀方向（示意） |
|--------------|------------|--------------------------------|
| `T10YIE`（10Y 盈虧平衡通膨） | % | **上升**：市場對長期通膨定價上移；**下降**：通膨擔憂緩和（仍受流動性與期限溢價干擾）。 |
| `T10Y2Y`（10Y−2Y 殖利率差） | % | **正值且擴大**：曲線變陡，常與「復甦／再通膨」敘事並列討論；**倒掛（負值）**：歷史上常與「衰退機率討論」並列，但 **領先落後不固定**。 |
| `VIXCLS` | 指數 | **< 15**：常稱偏低波動；**20～25**：偏警戒；**> 30**：恐慌情緒常升温（非交易信號）。 |
| `NFCI`（全國金融狀況） | 指數 | **> 0**：常描述金融條件相對 **緊**；**< 0**：相對 **鬆**（芝加哥聯準編制，請以官方說明為準）。 |

### 7.6 美國「發電燃料占比」（EIA 報表／未來可接 API）— 看占比時的 Spec

| 項目 | 說明 |
|------|------|
| **單位** | 通常為 **% of generation** 或 **億千瓦時**，以 EIA 表頭為準。 |
| **「核能占比」** | 美國核能發電占比 **長年大致在固定區間緩慢變動**（機組除役與延役會影響）；**短週期暴漲暴跌不常見**。若週報只看油價而沒看發電结构，**無法**推論核能是否變主能源。 |
| **「天然氣」** | 美國 **氣電** 占比高時，**氣價與發電結構** 會互相牽動；讀月報比讀情緒可靠。 |
| **「風／光」** | 看 **裝機與實際發電量** 差異（容量因子、天氣）；占比上升 **是長期趨勢＋季節性** 疊加。 |

## 八、核能進展與近期發展（與本表其餘欄位同一處整理）

此節把 **「機組事實／發電與停機／市場情緒」** 分層列在同一處；每週不必開很多檔案，依 **三欄檢查** 即可。

### 8.1 三層資料各自回答什麼

| 層次 | 回答的問題 | 代表來源（連結） |
|------|------------|------------------|
| **A. 機組與建案（存量／事件）** | 全球多幾台在建、商轉、除役？哪國政策或執照有變？ | [IAEA PRIS](https://pris.iaea.org/)（資料庫）；[World Nuclear Association](https://world-nuclear.org/)（產業整理／國家頁） |
| **B. 發電與停機（短期供給）** | 美國核能實際發多少、停機是否異常？ | [EIA — Nuclear](https://www.eia.gov/nuclear/)（總覽）；[EIA Electricity](https://www.eia.gov/electricity/data.php)（與整體燃料占比一併看） |
| **C. 燃料與股價敘事（輔助）** | 市場對鈾／相關資產的情緒？（**易與建廠進度脫鉤**） | 產業報價／財經媒體彙整（自行選固定 1～2 家即可） |

### 8.2 每週核能三欄（貼在日誌或週報最上方即可）

| 欄位 | 本週記一句即可 |
|------|----------------|
| **① PRIS** | 全球 **在建機組數／裝機容量** 與上週或上月比：有無變化？變化來自哪一區？ |
| **② EIA（美）** | **核能發電量** 或 **Nuclear plant generator outages** 與近期平均比：偏高／正常／停機偏多？（以官方表為準） |
| **③ 政策／產業事實** | [WNA](https://world-nuclear.org/) 或 **NRC 等監管機構** 一則 **可核對日期** 的消息（新執照、延役、建案延遲等）；避免只寫「概念股漲跌」。 |

### 8.3 與 EIA API 的銜接（你已有 Key）

- 在 [EIA API Dashboard](https://www.eia.gov/opendata/browser/) 選 **Electricity** 或 **Nuclear plant generator outages** 等路由，用 **「API」按鈕** 產生 v2 網址，再決定是否併入 `run_weekly_snapshot.py`（與既有 WTI 測試同一支金鑰）。  
- **讀比寫優先**：若尚未接 API，每週手動看 **EIA Nuclear 頁＋PRIS** 仍足夠建立事實感。

### 8.4 判讀備忘（核能專用）

- **占比與機組數變化通常慢**：一週內若只有「股價大漲」而 **PRIS／EIA 無對應事件**，多數是敘事或資金輪動。  
- **停機多** → 短期可供電量可能降；**不等於**政策反核或擁核反轉，要對照官方說明。  
- **鈾價** → 反映採購與情緒；**不能單獨**證明「核能已成主能源結構」。
