# 自學課程：AI × 指令 × 專案架構（一步一步）

給 **完全新手、習慣靠 AI 助理幫忙** 的你。  
每一課都有：**目標 → 你要做的事 → 怎麼知道自己學會了 → 下一課**。

**建議節奏：** 每天 **1 課**（約 20～40 分鐘）；想快可以合併，但不要跳過「自評檢查」。

**搭配文件：** 先瀏覽過 **`docs/AI與程式入門_專案架構總覽.md`**，本課程是「帶你做」。

**簡報／Word 雙欄速覽：** 同資料夾內 **`自學課程_雙排介紹.pptx`**、**`自學課程_雙排介紹.docx`**（左欄觀念、右欄操作／自評）。若改課程內容後要重產：

```powershell
cd C:\Users\User\.cursor-tutor
py -m pip install -r docs/requirements_handouts.txt
py docs/generate_course_handouts.py
```

## 第 0 課：專案地圖與學習方式

**目標：** 知道「學完每一課」代表什麼；知道遇到問題先查哪。

**請做：**

1. 打開 **`docs/AI與程式入門_專案架構總覽.md`**，用 10 分鐘掃過標題与小節。
2. 在檔案總管打開 **`C:\Users\User\.cursor-tutor`**，確認看得到 **`ai_agents`**、**`etoro_trading`**、**`local_agent_demo`**、**`docs`**。

**自評：** 你能用自己的話說出：「Cursor 里的 AI」和「本機跑的 Python 腳本」差在哪嗎？（一句話即可）

**下一課：** 第 1 課。

---

## 第 1 課：檔案總管 + 專案根目錄

**目標：** 之後任何教學說「在 repo 根目錄」，你都知道是哪一層。

**請做：**

1. 進入 **`C:\Users\User\.cursor-tutor`**（這就是 **repo 根目錄**）。
2. 打開 **`ai_agents`**，找到 **`選單_啟動AI_Agent.bat`**（先不要雙擊，只確認位置）。
3. 打開 **`etoro_trading`** → **`啟動檔`**，確認有 **`一鍵_Ollama摘要.bat`**。

**自評：** `ai_agents` 和 `etoro_trading` 哪一個是「統一入口」、哪一個是「eToro 主專案」？

**下一課：** 第 2 課。

---

## 第 2 課：終端機第一課 — `cd` 與目前位置

**目標：** 會用終端機「站到」專案根目錄。

**請做：**

1. 在 Cursor 開 **終端機**（Terminal），或開 **PowerShell**。
2. 輸入（可複製貼上）：

   ```powershell
   cd C:\Users\User\.cursor-tutor
   ```

3. 再輸入：

   ```powershell
   dir
   ```

   確認列表里有 **`ai_agents`**、**`etoro_trading`**。

**自評：** `cd` 在做什麼？若你現在想進 `ai_agents`，下一行該打什麼？（提示：`cd ai_agents`）

**下一課：** 第 3 課。

---

## 第 3 課：Python — `py` 與跑一行字

**目標：** 確認電腦叫得動 Python。

**請做：**

1. 終端機已在 **`C:\Users\User\.cursor-tutor`**（第 2 課）。
2. 執行：

   ```powershell
   py -c "print('hello')"
   ```

   應看到 **`hello`**。

**自評：** `py -c "..."` 代表「用 Python **立刻執行**一小段字」，對嗎？

**下一課：** 第 4 課。

---

## 第 4 課：`py -m` 與專案入口

**目標：** 理解「為什麼常打 `py -m etoro_trading.scripts ...`」。

**請做：**

1. 在 **repo 根目錄** 執行：

   ```powershell
   py -m etoro_trading.scripts --help
   ```

2. 捲動看一下有哪些**子命令**（不用全記）。

**自評：** `-m` 和「直接雙擊 `.bat`」有什麼共通點？（都是：**用正確方式啟動已寫好的程式**）

**下一課：** 第 5 課。

---

## 第 5 課：`pip` — 安裝與「套件 ≠ 付費」

**目標：** 會裝套件；知道 **`openai` 套件** 與 **OpenAI 付費 API** 是兩件事。

**請做：**

1. 執行（已裝過也沒關係）：

   ```powershell
   py -m pip install -r local_agent_demo/requirements.txt
   ```

2. 重讀 **`local_agent_demo/README.md`** 里「會不會用到付費 OpenAI」那一小段。

**自評：** 用一句話解釋：為什麼裝了 `openai` 套件，仍可能 **0 元**用本機 Ollama？

**下一課：** 第 6 課。

---

## 第 6 課：Ollama — 開啟、模型、本機網址

**目標：** 知道 Ollama **是服務**，聊天視窗只是其中一種用法。

**請做：**

1. 從開始選單開啟 **Ollama**（工作列有圖示）。
2. 終端機執行：

   ```powershell
   ollama list
   ```

   （若指令找不到，用 **`ai_agents\啟動_Ollama桌面程式.bat`** 或到安裝目錄；重開終端再試。）
3. 瀏覽器打開 **`http://127.0.0.1:11434`**（可能顯示簡短字樣，代表服務在聽）。

**自評：** 本機 API 的預設埠是 **11434**，對嗎？

**下一課：** 第 7 課。

---

## 第 7 課：雙擊 `ai_agents` — 每個入口試一次

**目標：** 把「入口」和「實際程式位置」連起來。

**請做：**

1. 雙擊 **`ai_agents\選單_啟動AI_Agent.bat`**，至少選 **4**（開 Ollama 桌面）成功一次。
2. （選做）選 **3** 跑 **`local_agent_demo`**：若失敗，看錯誤是 **Ollama 沒開** 還是 **別的**。

**自評：** 你能對照 **`ai_agents/README.md`** 的表格，說出「選 2」實際跑的是哪個 Python 子命令嗎？

**下一課：** 第 8 課。

---

## 第 8 課：eToro 摘要 — 有 log / 沒 log

**目標：** 理解 **腳本依賴資料**；沒有 `daily_*.log` 不是「壞掉」，是**還沒產生輸入**。

**請做：**

1. 打開資料夾 **`etoro_trading\data\automation_logs`**（若沒有就記下「目前是空的」）。
2. 雙擊 **`一鍵_Ollama摘要.bat`**（`etoro_trading\啟動檔` 或 **`ai_agents\啟動_eToro_Ollama摘要一鍵.bat`** 皆可）。
3. 閱讀終端機訊息：有沒有找到 log？摘要檔寫在哪？

**延伸（選修）：** 閱讀 **`etoro_trading/docs/日常自動化_排程說明.md`** 前兩節，知道 log 從哪來。

**自評：** 若沒有 log，你會先做「跑日常自動化」還是「改用手動指定 `--log`」？（兩種都可以，重點是你知道原因）

**下一課：** 第 9 課。

---

## 第 9 課：讀懂一支小程式（10 行以內）

**目標：** 不怕打開 `.py`；能指認「匯入、設定、執行」。

**請做：**

1. 用 Cursor 打開 **`local_agent_demo/config.py`**。
2. 找出三樣東西：**OLLAMA_BASE_URL**、**OLLAMA_MODEL**、**MAX_AGENT_STEPS**。
3. 問自己：改 **MODEL** 會影響什麼？（答：呼叫本機時用哪個模型名稱。）

**自評：** 你能指著一行說「這是設定，不是邏輯」嗎？

**下一課：** 第 10 課。

---

## 第 10 課：`local_agent_demo` — 改一句話看結果

**目標：** 體驗「改提示詞 / 改行為」與輸出的關係。

**請做：**

1. 打開 **`local_agent_demo/agent.py`**，找到 **`SYSTEM = """..."""`** 里**給模型看的規則**。
2. 加一行無害規則，例如：「回答使用者時請在開頭加【demo】」。
3. **Ollama 開著**，在 repo 根目錄執行：

   ```powershell
   py local_agent_demo\agent.py 測試
   ```

4. 看輸出是否出現 **【demo】**（模型有時不 100% 遵守，這本身也是一課）。

**自評：** 你發現「改字」不一定「百分之百生效」，因為那是 **機率模型**，對嗎？

**下一課：** 第 11 課。

---

## 第 11 課：`.env`、本機 API vs 雲端

**目標：** 知道**設定**如何決定「錢與資料往哪流」。

**請做：**

1. 打開 **`etoro_trading/.env.example`**（若沒有 `.env` 沒關係，看 example 即可）。
2. 找到 **OLLAMA_** 開頭的列，對照 **`Ollama_本機摘要設定.md`** 一節。
3. 用自己的話寫兩句話：  
   - 本機 **`127.0.0.1:11434`**  
   - 若改成 **`api.openai.com`** 會怎樣（需要金鑰、可能計費）

**自評：** 你能說明為什麼 **不要把含金鑰的 `.env` 貼到公開聊天** 嗎？

**下一課：** 第 12 課。

---

## 第 12 課：排程與自動化心態（選修）

**目標：** 知道「每天自動」是 **OS 或腳本** 在叫你的程式，不是魔法。

**請做：**

1. 閱讀 **`etoro_trading/docs/日常自動化_排程說明.md`**（不必立刻設定）。
2. 寫下：若你要「每天早上 9 點跑摘要」，你需要 **哪兩個東西** 同時成立？（例：Ollama 開著、有 log；或先跑自動化再摘要。）

**自評：** 你能接受「自動化 = 把**你已經手動成功過一次**的指令，交給排程重複」嗎？

**畢業：** 恭喜走完一輪。建議 **隔一週** 從第 7 課重做一次（會快很多），加深肌肉記憶。
