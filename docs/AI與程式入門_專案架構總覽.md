## 2. 幾個一定要會的「電腦積木」

### 2.1 檔案與資料夾

- **檔案**：`.py` 是 Python 程式、`.md` 是說明文件、`.bat` 是 Windows 一鍵執行的小腳本。
- **資料夾**：把專案分區。你的專案根目錄大約是 **`C:\Users\User\.cursor-tutor`**（下面簡稱 **repo 根目錄**）。

### 2.2 「程式」是什麼？

就是**一串指令**，由 **Python**、**Node（npm）** 等執行。  
執行時通常要告訴電腦：**在哪個資料夾、用哪個指令**。

### 2.3 終端機（Terminal / PowerShell / CMD）

一個**打字下指令**的視窗。很多教學寫：

```text
py -m pip install 某套件
```

代表：請在終端機裡**逐字輸入**（或複製貼上）後按 Enter。

### 2.4 為什麼常說「在 repo 根目錄執行」？

因為專案設計成：從 **`.cursor-tutor` 這一層** 執行時，Python 才找得到 `etoro_trading` 這種**套件名稱**。  
若你在錯的資料夾執行，容易出現「找不到模組」。

## 3. 指令基礎（最常見的三類）

### 3.1 切換資料夾

```powershell
cd C:\Users\User\.cursor-tutor
```

`cd` = change directory（換目錄）。

### 3.2 用 Python 跑模組

```powershell
py -m etoro_trading.scripts ollama-summarize
```

- **`py`**：呼叫你電腦上的 Python。  
- **`-m`**：用「模組方式」執行（專案已包好入口）。  
- 後面是**子命令**，等同「選功能」。

### 3.3 安裝套件

```powershell
py -m pip install -r local_agent_demo/requirements.txt
```

- **`pip`**：Python 的套件管理員。  
- **`-r 檔案`**：依清單一次安裝。  

**注意：** 安裝 **`openai` 這個套件** ≠ 付費使用 OpenAI 公司 API。套件只是**程式庫**；連到哪個網址、要不要錢，由 **設定里的網址（例如本機 Ollama）** 決定。

## 4. 寫程式的基礎觀念（精簡版）

### 4.1 程式在做什麼？

大致就是：**輸入 → 處理 → 輸出**。  
例如：讀一個 log 檔 → 送給模型 → 寫出一個摘要檔。

### 4.2 函式、模組、套件

- **函式**：一段可重複使用的邏輯（有名字，可帶參數）。  
- **模組**：一個 `.py` 檔，裡面有多個函式。  
- **套件**：很多模組組成一個專案（例如 `etoro_trading`）。

### 4.3 什麼是 API？

程式跟**另一個程式或服務**用**約定好的格式**溝通（常是網路網址 + JSON）。  
**本機 Ollama** 也提供 API，所以你的腳本可以「用 HTTP 問它問題」。

### 4.4 `.env` 是什麼？

放**設定**的檔（不要分享給別人），例如 API 網址、模型名稱。程式讀取後決定「連哪裡、用哪個模型」。

## 5. AI 相關：名詞一次認識

| 名詞 | 白話 |
|------|------|
| **LLM（大語言模型）** | 吃文字、產文字（或結構化輸出）的模型。 |
| **Ollama** | 在你電腦上**跑模型、提供 API** 的軟體；**本機**為主，**不經 OpenAI 官方就不會有 OpenAI 帳單**。 |
| **雲端模型（:cloud 等）** | 模型在遠端伺服器，通常要網路與帳號。 |
| **Agent（代理人）** | **模型 + 迴圈 + 你寫好的工具**：模型決定「下一步」，你的程式負責真的讀檔、打 API。 |
| **Cursor 里的我** | 幫你**讀寫專案、解釋、產生命令**；**不是你電腦上常駐的語音或排程**。 |
| **Claude Code / Codex CLI** | **終端機里的編程工具**，通常連 **Anthropic / OpenAI**，要各自帳號與方案。 |

## 6. 你這個 repo 的「系統性架構」怎麼拼起來？

### 6.1 資料夾分工（記這張表就夠用）

| 資料夾 | 做什麼 |
|--------|--------|
| **`ai_agents/`** | **統一入口**：一堆 `.bat`，幫你 `cd` 到正確位置再啟動（語音摘要、教學 Agent、開 Ollama…）。 |
| **`etoro_trading/`** | **eToro 輔助專案**：腳本、UI、資料、文件；含 **Ollama 摘要 log**。 |
| **`local_agent_demo/`** | **最小教學用 Agent**：示範「模型 + 工具迴圈」。 |
| **`docs/`（本檔所在）** | **跨專案說明**；eToro 細節仍在 **`etoro_trading/docs/`**。 |

### 6.2 「為什麼雙擊 .bat 就會對？」

`.bat` 里通常有兩件事：

1. **`cd /d "%~dp0.."`** 這類指令 → 先回到 **repo 根目錄**。  
2. **`py -m ...`** → 用正確路徑執行 Python。

所以**你不用記完整路徑**，入口幫你收斂。

### 6.3 「為什麼有時要我本機裝 Node、有時要 Python？」

- **Python**：你這個 repo 里 **eToro 腳本、Ollama 摘要、local_agent_demo** 都是 Python。  
- **Node / npm**：**Claude Code、Codex CLI** 這類工具是用 **npm 全域安裝**的，所以要 Node。

它們是**不同生態系**，可以並存。

## 7. 「我都靠你處理」時，你實際上該保留的意識

1. **我幫你改的是檔案**；**真正執行**多半還要你：**雙擊 bat** 或在終端機 **跑指令**。  
2. **帳單與隱私**：本機 Ollama vs 雲端 Claude/OpenAI **不一樣**；敏感金鑰放 `.env`，不要貼到公開聊天。  
3. **錯誤訊息是線索**：例如 `ModuleNotFoundError` → 常是 **還沒 pip install**；`could not connect` → **Ollama 沒開**。
