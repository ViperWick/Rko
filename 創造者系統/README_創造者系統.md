# 創造者系統 — 使用說明

> 這是「運轉層」的入口。戰略與規則請看《創造者系統整合手冊》；這裡是每週／每月會用到的三份檔案。

---

## 檔案說明

| 檔案 | 用途 | 更新頻率 |
|------|------|----------|
| **本週創造者.md** | 本週要交的產出、一件 B/C 行動、探索時間 | 每週一寫，週末勾選 |
| **我的產出清單.md** | 已發布的內容／工具／連結，方便回顧與複用 | 每次發布就加一筆 |
| **探索清單.md** | 想試的點子、工具、主題；從發現端收回來的待辦 | 隨時加；每月清一次 |
| **發現文檔收納/** | 把 Word / PPT / Excel / TXT 丟進來，執行收納腳本後會更新「發現文檔索引」 | 有檔案就丟入；要更新索引時執行腳本 |
| **專案清單.md** | 程式專案收納：列出你的專案（如 eToro 交易程式）、路徑與展示方式 | 有專案就加一列 |
| **創造者系統_ui.py** | 簡易 Web 介面：總覽、本週／產出／探索／專案／發現文檔索引、一鍵收納 | 雙擊 開啟介面.bat 啟動 |

---

## 發現文檔收納（把檔案丟進去就收進系統）

1. 把 **Word（.docx）、PPT（.pptx）、Excel（.xlsx）、純文字（.txt）** 丟進 **發現文檔收納/** 資料夾。
2. 雙擊 **收納發現文檔.bat**（或在本目錄執行 `python 收納發現文檔.py`），會自動安裝依賴並更新索引。
3. 打開 **發現文檔索引.md** 即可看到所有已收納檔案與內容預覽（依修改日期排序）。

**其他**：雙擊 **創造者系統.bat** 可開啟本資料夾；雙擊 **開啟介面.bat** 可開啟**簡易 Web 介面**（總覽、本週創造者、產出／探索／專案清單、發現文檔索引、一鍵收納）。

---

## 每週節奏（建議：週一約 15 分鐘）

1. 打開 **本週創造者.md**，填寫本週的「固定產出」「一件 B 或 C」「探索時間」。
2. 週末：在同一份裡打勾完成與否，沒完成就寫一句原因。

---

## 每月節奏（建議：月底約 30 分鐘）

1. **回顧**：看「我的產出清單」這月發布了幾件；看「探索清單」有沒有把發現寫回下一輪產出。
2. **微調**：回《創造者系統整合手冊》Part 2.4 四格、Part 4 行動選項，看要不要改。
3. **下月**：決定下月固定產出；從探索清單挑 1～2 個「本月要試」的。

---

## 與四塊積木的對應

- **需求端** → 手冊 Part 2.4 第一格「我服務誰、解決什麼」；每月回顧時對齊。
- **生產端** → 「本週創造者」每週填產出；「產出清單」只記已發布。
- **餘裕端** → 「本週創造者」每週寫死一段探索時間；「探索清單」當這段時間的選單。
- **發現端** → 探索後寫進探索清單，每月回顧時把 1～2 個收進下月產出或手冊下一步。
