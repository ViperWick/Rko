# 發現文檔收納 — 使用方式

把 **Word（.docx）、PPT（.pptx）、Excel（.xlsx）、純文字（.txt）** 檔案直接丟進這個資料夾（或裡面的子資料夾也可以）。

然後在「創造者系統」資料夾裡執行收納腳本，系統會：

1. 掃描本資料夾內所有上述類型的檔案  
2. 讀取檔名、類型、修改日期  
3. 盡量擷取內容預覽（前幾行或摘要）  
4. 自動更新 **發現文檔索引.md**，讓你在一份清單裡看到所有已收納的發現文檔  

---

## 步驟

1. **丟檔案**：把要收納的 .docx / .pptx / .xlsx / .txt 放進此資料夾（或子資料夾）。  
2. **執行收納**：在專案目錄執行  
   ```bash
   pip install -r requirements_收納.txt
   python 收納發現文檔.py
   ```  
   或在 Cursor 終端機從 `創造者系統` 目錄執行上述指令。  
3. **看索引**：打開上一層的 **發現文檔索引.md**，即可看到所有已收納檔案與預覽。

---

*索引會依「修改日期」排序，最新的在前。*
