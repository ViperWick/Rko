# 專案／程式清單

> 把「程式專案」收納進創造者系統：列在這裡的專案 = 你的產出或正在維護的程式。可從這裡快速連結到 README、展示介面或程式碼位置。

**和「發現文檔收納」的差別**：發現文檔收納是 **Word / PPT / Excel / TXT** 檔案；這裡是 **程式專案（資料夾）**，用一筆一筆列出來即可，不必把整個專案丟進某個資料夾。

## 使用方式

- **新增專案**：在上表加一列，填「專案名稱、一句說明、路徑或連結、別人怎麼看（例如簡易展示頁或 README）」。
- **和「我的產出清單」的關係**：若專案有「對外發布」（例如上架、開源、給客戶看），可在「我的產出清單」也記一筆，這裡當成「程式產出」的索引。

---

*程式專案不必丟進「發現文檔收納」；用本清單收納即可。*
